# 视频反推规范（R58）
> **R70 接口**：反推出的分镜同样写成 `分镜/镜头表.md`（六列，逐秒指令覆盖原片每一秒）＋`分镜/文本分镜.md`（十一字段、逐格四象限）；镜号 `镜 <集>-<序> / N s`，镜长照原片切点。旧稿单份 `分镜/镜头表.md` 照旧可读。


> 适用：用户给你一段视频，并在同一轮里明确说「反推」。
> 产出：**只有 `分镜/镜头表.md`、`分镜/文本分镜.md` 与 `分镜视频.md` 三份**。剧本、资产提示词、人物／场景／道具资产、项目交接，一概不出。
> 目标：把这两份提示词再喂给 H3 生成，出来的片子跟原片**无差别**。

---

## 一、先判断：这轮到底算不算反推

| 用户怎么说 | 怎么做 |
|---|---|
| 「这条视频反推一下」「照这条片子出提示词」「逆向推出分镜和分段」 | 进入反推模式，只交两份 |
| 「看看这个视频」「这条讲什么」「分析一下这段」 | 不是反推，先正常答，末尾问一句「要不要按原片反推成分镜与分段提示词」 |
| 只给视频、什么都没说 | 先问清要干什么，不擅自开工 |
| 给了视频 + 说「按这个拍一集新的」 | 这是参考不是反推：走常规流程，视频只当视觉参考 |

判定的关键就两条：**有视频 + 有「反推」意图**。两个条件缺一个都不进这条流程。

---

## 二、看清原片的办法（先看后写，不许凭印象）

### 2.1 抽帧

有 ffmpeg 就用它，按每秒 2 帧抽，切点附近补抽：

```powershell
ffmpeg -i "原片.mp4" -vf fps=2 -q:v 2 "帧\%04d.jpg"
ffmpeg -i "原片.mp4" -vf "select='gt(scene,0.3)'" -vsync vfr "切点\%04d.jpg"
```

没有 ffmpeg 就用宿主自带的视频理解／抽帧能力（豆包办公可走视频理解工具，直接问「逐镜描述景别、机位、动作、台词、时长」）。两条口径一样：**一镜一镜看，不整段概括**。

### 2.2 时间轴表

边看边填，这张表就是分镜的底稿：

| 镜号 | 起–止（秒） | 时长 | 景别 | 机位与高度 | 运镜 | 构图 | 人物与朝向 | 动作起止 | 表情／视线 | 光位／色温 | 台词 | 声音 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 1-1 | 0.0–2.4 | 2.4 | 中景 | 平视 1.1 m | 固定 | 人在画左三分之一 | 男一 面朝画右 | 抬右手抵胸→眼皮半垂 | 疲惫三成／看门缝 | 窗光画左、冷白 | 无 | 风声＋布料声 |

填表规矩：

1. **时长按帧算**，不用眼睛估；一镜起止各记到 0.1 秒。
2. **运镜**写方向＋速度（推／拉／摇／跟／固定，慢/中/快），不写「有运镜」。
3. **构图**写人在画左／画右／居中、头顶留白多少、前景有没有遮挡物。
4. **动作起止**写「从什么姿势到什么姿势」，中间施力点与承重脚各记一句。
5. **台词**逐字记；听不清的写 `（听不清）`，并记这句持续几秒（口型段长度）。

## 三、写分镜（第一份）

格式与常规分镜完全一致（R70 六列镜头表＋文本分镜，不写绝对时间码），只多两条纪律：

1. **镜号按原片切点排**，`镜头 1-1`、`1-2`…；原片一镜就是一镜，不合并、不拆分。
2. **「拍摄手法」栏写原始参数**：`中景｜平视 1.1 m｜固定机位｜2.4 秒｜理由：交代他在床沿的静止起势`——景别、机位、运镜、时长必须与时间轴表一字不差。

「提示词」栏结构（R57 照写）：

```
承接：本集开篇，男一坐在床沿、右手把手机抵在胸口、眼皮半垂，重心压在左臀
起幅：……（原片的构图＋光位＋人物状态，逐项照抄原片）
……
转场出：同向运镜（推接推）｜末帧：手机收到腰侧、下巴抬起、重心在左臀、视线停在门缝｜接：下一镜从门缝方向推近，接住他抬起的下巴与垂在腰侧的右手
```

**反推时「承接」照原片真实转法写**：原片是硬切就写 `hard cut 至 <场名>`，原片是遮挡就写遮挡，原片用了黑场／叠化也照写并注明。

## 四、空缺图槽怎么写（这条最容易写错）

反推时用户手里**没有**实拍资产图，所以：

- **不许编真编号**：不写 `@C01 周野`、`@S01 出租屋`、`@P01 饭盒`。
- **不许写「已出图」「见附图」**。
- **一律写占位种类名**：人物类 `人物一`／`人物二`…，场景类 `场景一`／`场景二`…，道具类 `道具一`／`道具二`…。

### 4.1 排号规则

| 情况 | 写法 |
|---|---|
| 全片只有一个人物 | `人物一` |
| 多个人物 | 按**出场顺序**：第一个露脸的 `人物一`，第二个 `人物二`，依次顺排 |
| 同一人物反复出现 | 始终 `人物一`，不换号、不回收 |
| 换了衣服但仍是同一人 | 仍 `人物一`（换装不换号） |
| 只闻其声、未见其人 | 不占人物号，只在台词行写角色名，配音处理 |
| 场景 | 每个不同地点一个号：`场景一`、`场景二`…（同一地点的不同机位仍是同一个号） |
| 道具 | 每个可辨认的关键物件一个号：`道具一`、`道具二`…；背景杂件不编号 |

### 4.2 落位写法

分镜「参考图」栏：

```
@图片 1 人物一（空缺占位）　@图片 2 场景一（空缺占位）　@图片 3 道具一（空缺占位）
```

分段元数据「参考图」栏只写 `@图片 1`、`@图片 2`；`subject_definitions` 与 `retention_analysis` 写中文名：

```
  subject_definitions:
    <Subject 1>（图片名：人物一）: The reference supplies facial identity, hair and costume only; pose, head angle and eyeline follow the shot description. main orientation: facing frame right.
    <Subject 2>（图片名：场景一）: The reference supplies environment layout and lighting only; camera angle and view direction follow the shot description.
  retention_analysis:
    <Subject 1>（图片名：人物一）: fully_preserved; head angle and eyeline are reblocked per shot; reference frontal orientation is not preserved.
```

## 五、占位不等于省描写（无图的「像」靠字面撑）

没有参考图，模型只会照文字画。所以每个主体的固定特征句必须写足，并且在每次出现时**原样复述**：

**人物固定特征句（示例）**

> 男一，三十岁上下，短寸黑发、鬓角修短，长方脸、颧骨略高、下颌线硬，眉骨压眼、单眼皮、眼白偏冷灰，鼻梁直、鼻翼窄，唇薄、嘴角平；身高一米八、肩宽腰窄；深灰棉麻长衫、袖口卷到前臂中段、衣摆下缘磨白起毛，黑布鞋、鞋头有灰；右手腕一道旧疤。

**场景固定特征句（示例）**

> 场景一，老旧出租屋房间，白墙泛黄、墙角有水渍痕；画左一张单人床（床单灰白、被角卷起），床边一只矮木床头柜，柜上一盏铁皮台灯（灯罩边缘磕掉漆）；画右一扇木门、门缝透进走廊冷白光；地面木地板起翘、散着几张纸。

**道具固定特征句（示例）**

> 道具一，黑色直板手机，六寸上下、边角有磕痕、屏幕右下角一道裂线，深灰硅胶壳，镜头孔位偏左。

三条纪律：同一角色各镜之间不加减特征；服装换了就写清「换成 X，脸与身材不变」；原片看不清的细节（比如鞋带颜色）**不猜**，写到能看见的那一层为止。

## 六、写分段（第二份）

1. **逐字照 `references/分镜视频模板.md`**：`*` 元数据六行、六段缩进、台词块后置。
2. **分段边界按原片切点对齐**：一段包 2–5 镜、4–10 秒整数；把时间轴表的时长相加核对，合计必须等于分镜合计，也必须等于原片时长（±1 秒）。
3. **每段 `Entry:` 与 `Exit:`**：第 1 段写 `Entry: opening segment; <首帧状态>; the first beat only holds.`；后续段写 `Entry: continuing from the previous segment, <上一段末帧状态>; the first beat only holds, no new action.`；末镜之后写 `Exit: the segment ends on <定格状态>, held for the last three to five frames; hand-off to the next segment by <方式>.`（原片最后一段写 `episode ends on ... held to the last frame`）。
4. **原片的转场照写**：原片推接推就写同向运镜，原片硬切就写 hard cut，原片黑场／叠化就写黑场／叠化——R57 的禁令在反推里让位于「复刻原片」。
5. **台词只写一次**：`(Sx) 角色：[Chinese] 原文`，`(Sx)` 逐行递增；听不清的写 `(Sx) 角色：[Chinese] （听不清）`。

## 七、交付前怎么验（无差别四条）

逐条核，不对就回去改，不许标称「已还原」：

1. **时长与镜数**：`逐镜时长相加 = 分段时长相加 = 原片时长（±1 秒）`；镜数与原片一致。
2. **画面**：任挑 3 镜，把原片截帧和提示词并排看——景别、机位高度、人在画左还是画右、运镜方向，四样都能对上。
3. **动作**：每镜首帧姿势与末帧姿势都对得上原片；朝向、重心、手持物、光位不跳。
4. **声音与台词**：台词句数一致、口型段长度一致；环境底声与动作声写得出来（门轴响、脚步、布料摩擦、水流、风）。

自检命令（只查这两份）：

```powershell
python "<技能目录>\scripts\check_rule.py" --project "<项目目录>" --reverse
```

反推模式下缺 `剧本.md`、缺三类资产不报错；查的是：两份文件是否齐、六列是否齐、六段是否齐、时间码口径、时长合计是否相等、R57 转场标记、占位命名是否合规（出现 `@C01` 这类真编号或「已出图」会报 FAIL）。原片用了黑场／叠化加 `--allow-transition` 放行。

## 八、常见坑

1. **把几镜并成一镜图省事** → 生成出来节奏就变了。原片一镜就是一镜。
2. **用「电影感」「氛围感」代替参数** → 反推要的是可复现参数：景别、高度、焦段感、运镜速度、光位。
3. **自己编剧情补动机** → 只写看见的动作，不写「他其实在想……」。内心独白只照原片台词写。
4. **编 C／S／P 编号** → 用户没给资产表，编号一编就假，全部写占位名。
5. **占位名不统一** → 同一个人一会儿 `人物一` 一会儿 `男人甲`，模型认不出是同一人，跨镜就换脸。全片只用一个号。
6. **台词听不清就自己编** → 写 `（听不清）`，保留口型长度；编词等于改了原片。
7. **顺手给了剧本和资产** → 用户明确说「别的都不用给」，多给就是违规。
