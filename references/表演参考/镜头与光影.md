# 镜头与光影（景别／构图／运镜／光／转场）

用法：写分镜「拍摄手法」与分段「场景与轴线」「提示词」时，从这里选景别、机位、运镜、光位；一个镜头只写一个主运镜，别堆三个。所有镜头都是**第三视角观察**，机位不附在人物身上，人物不看镜头。

## 一、景别（7）

| 景别 | 取景 | 什么时候用 |
|---|---|---|
| 极远景 | 人在环境里很小 | 开场、宿命感、人物渺小 |
| 大全景 | 全身＋环境 | 交代空间、势力、群像 |
| 全景 | 全身 | 走、跑、打、舞蹈、动作完整 |
| 中景 | 膝盖以上 | 对话、两人互动、最常用 |
| 近景 | 胸部以上 | 表情、语气、情绪落点 |
| 特写 | 肩以上 | 眼神、嘴角、泪、关键反应 |
| 极特写 | 眼、唇、手指、物件局部 | 微表情、手部、证据、刀锋 |

分段写法：`近景（胸上）·平视`；不要写「镜头对着她」，写「机位在她前方 1.5 米、平视」。

## 二、构图（6）

- **中心构图**：主角正中，强调气场、压迫。
- **三分法**：人放在交叉点，画面平衡，适合对话。
- **对称构图**：宫殿、法庭、祠堂，庄重。
- **框架构图**：透过门、窗、镜子、帘子拍人，做窥视与距离。
- **低角度仰拍**：增强压迫、权力、气场；配下跪、训话。
- **高角度俯拍**：表现脆弱、无助、被审视；配崩溃、认命。

## 三、运镜（11）

| 运镜 | 效果 | 用法 |
|---|---|---|
| 固定 | 稳定、客观 | 情绪特写、微表情、对峙 |
| 慢推 | 逐渐逼近 | 情绪升级、意识到真相 |
| 快推 | 突然放大 | 惊吓、冲击、拍案 |
| 拉镜头 | 揭示环境、反差 | 从脸拉到空屋、从人拉到战场 |
| 横移 | 跟随移动 | 走路、走廊、并排走 |
| 环绕 | 360° 围人 | 紧张、仪式感、重逢 |
| 升降 | 上升／下压 | 气势、权力变化、跪与起 |
| 手持晃动 | 纪实、紧张 | 追逐、打斗、失控 |
| 跟拍 | 跟着人走／跑 | 奔跑、逃、赶路 |
| 甩镜头 | 快速转场 | 打脸、转场、节奏点 |
| 变焦 | 不动机位改焦段 | 人群中锁定一张脸 |

规则：一个镜头只写一个主运镜；运镜要有起幅与落幅，写清「从哪到哪、几秒到几秒」。

## 四、时段与光（5＋6）

| 时段 | 光感 | 情绪 |
|---|---|---|
| 清晨 | 柔和蓝光、薄雾 | 清新、清冷、开始 |
| 正午 | 顶光硬、阴影重 | 对峙、暴晒、无处躲 |
| 黄昏 | 金色逆光、长影 | 浪漫、伤感、告别 |
| 蓝调时刻 | 城市夜的前奏、冷蓝 | 孤独、等待 |
| 夜晚 | 霓虹、路灯、烛光 | 情绪浓、危险、私密 |

| 光源 | 写法 | 用法 |
|---|---|---|
| 自然窗光 | 窗在画左，光从左上 45° 入，柔边 | 室内情绪戏 |
| 烛光 | 单支烛在画右下，暖黄、摇曳 | 古代、私密、夜谈 |
| 霓虹 | 画外招牌，粉／蓝反射在脸侧 | 都市、赛博、雨夜 |
| 路灯 | 顶光偏暖，雨里有光斑 | 雨夜、等待、孤独 |
| 顶光 | 正上方硬光，眼窝投深影 | 审讯、压迫、审判 |
| 逆光 | 光在人物背后，轮廓亮、脸暗 | 剪影、神圣、离别 |

光位必须写方向、色温、强弱、落点；光变要写清起收阶段。原文没写光就不补（R40）。

## 五、转场（7）

- **物体遮挡**：手、扇、门扇、衣摆划过画面，切下一场。
- **相似动作**：前世今生同一个动作接上。
- **颜色匹配**：红衣接红烛、白雪接白衣、血接红盖头。
- **声音转场**：雷声接鼓声、哭声接雨声、门响接枪响。
- **黑白闪回**：回忆段落黑白，回现实恢复彩色。
- **水滴／雨滴**：水滴落下接时间流逝。
- **镜面**：镜中倒影切到另一场景／另一个人。

分段写法：`段尾：扇面遮满画面 → 段首：扇面移开已是三年后`；跨段接缝按 R24 写「前段末行＋后段首行」。
