# 表演参考库（R48 · R49）

来源：用户自备的四套资料——微表情 36 条、镜头与光影 4 篇、动作与肢体 8 篇、分镜与场景 8 篇。原稿里不少示例写「直视镜头／镜头即心上人的眼睛／第一人称主观视角」，与 R49 冲突，本库已统一改写为**第三视角观察、视线落在画外对象**，原稿那类写法不再采用。

## 一、什么时候读

- **写 `分段视频提示词.md` 之前，必须先查本库**：按这一段的情绪、动作、景别，进对应文件取肌肉清单与节拍；先判断这个角色、这个情境会不会这样做——会，就改写成这个角色的具体动作、幅度、速度与破功点，落进「提示词」逐秒行；不会就换一条或自拟。**本库是参考，不是整条照搬的模板**。
- 写 `分镜.md` 的「表情」「动作」「拍摄手法」时，同样可以查《微表情》《镜头与光影》《动作与肢体》。
- **命中与未命中都要说清**：交付报告写「参考命中：哭02 倔强压抑、动作06 手部特写」；本库没有的，写「参考未覆盖：…（自拟）」。不许一句「参考了」糊过去，也不许本库已有还自己另编一套，更不许把条目原文整段贴进提示词。

## 三、三条硬口径

1. **第三视角记录（R49）**：机位在画外，画面是「有人在旁边记录发生的事」，不是人物对着观众演。**只有镜头去找人物，没有人物去找镜头。** 人物**不看镜头、不找镜头、不朝镜头演、不对镜头笑、不往镜头上撞**。禁止写「直视镜头、看向镜头、望向镜头、对着镜头、盯住镜头、锁住镜头、找镜头、迎镜头、追镜头、镜头即××的眼睛、第一人称主观视角」。
2. **视线必须有落点**：写「视线落在 @C02 的手上／门缝／剑柄／桌面／远处窗口／地面的血迹」，不写「看着镜头」。需要「看向观众」时，改成看向画外的那个人或那个物件。
3. **微表情写三层**：先一句情绪词（什么情绪、几成、对着谁），再写眼睑／瞳孔／眉／嘴，再写呼吸／喉／泪／手／肩；至少三处可见变化，不许只写「她很伤心」「他很生气」。

## 四、资产图例外

人物三视图、面部特写、场景图、道具图是**参考图**，可以正对画面、平视镜头；R49 只管剧情里的分镜与分段，不管资产图。
