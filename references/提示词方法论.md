# 提示词方法论（R55 配套）

> 来源：《AI视频提示词方法手册》整理稿。
> 用法：只吸收与 MiniMax-H3 不冲突的部分；不覆盖 4–15 秒段长、220–260 秒一集、九栏、分镜不写时间码、Ref2VA 六段式、`references/分镜视频模板.md` 的 `(Sx) 角色：[Chinese] 原文` 台词格式、R54 视线控制。
> 本文件是写法参考；硬约束以 `制作规则原文.md` R55 与 `SKILL.md` 第 7 节为准。

## 一、复杂动作先锁关键帧

**适用**：接触、拥抱、比武、兵器咬合、多人身体交叠、训练素材里少见的非标准姿势。

**做法**：
1. 分镜「参考图」栏先指定关键帧：首帧、中段或尾帧，挂 `@图片 N`；
2. 关键帧只定姿势、构图与接触点，不复制参考图的正面朝向与视线（R54）；
3. 分段写「从这张关键帧的姿势开始，往哪个方向动、停在哪一帧」；
4. 普通走、坐、说、看不必强制。

**不适用**：靠关键帧替代动作描写。分段仍要写关节、肌肉、承重与受力结果。

## 二、动作写成因果链

**公式**：谁施力 → 作用到谁／什么 → 出现什么可见结果。

**合格**：
- 月光落地，他踩过，鞋底把光切断。
- 他右手扣住刀柄，虎口收紧，刀鞘被带得向左偏半寸。
- 她左手推门，门轴卡了一下，门缝只开到一拳宽。

**不合格**：
- 月亮很亮、他站着、地上有反光。（三条并列，没有作用关系）
- 他很紧张、动作很快、气氛压抑。（全是结论，没有可见事实）

**与 R50 的关系**：R50 的七件事一件不能少；因果链只负责把句子串起来，不替代锚点、朝向、肌肉、视线与道具位移。

## 三、概念替代形容词

**适用**：姿势、质感、风格、气势这类「形容词堆不出画面」的地方。

**做法**：
- 先写具体动作＋一个定性词：`右腿蹬住弓臂，双手把弦拉到耳侧，动作狠`；
- 或换通用视觉概念：`雪夜低垂红月`、`赛博朋克雨街`、`武将拉弓的狠劲`；
- 概念必须可拍、通用，不能是具体 IP 角色、演员、导演、画师、品牌。

**禁止**：
- `像哪吒拉弓`、`像某某电影`、`像某画师`——本尊或品牌物可能直接进画面；
- 用概念替代情绪词与肌肉描写。R5 的情绪词仍要写。

## 四、人先定死，镜头后补

**顺序**：
1. 人站哪：锚点哪一侧、离多远、朝哪边、哪只脚承重；
2. 人在做什么：起始动作、手在哪、视线落在哪；
3. 机位怎么动：类型、幅度、速度、停在哪。

**红线**：机位运动不许改人物身份、朝向与视线；不许先写「镜头绕到正面」，再让人物转头配合镜头（违反 R49／R54）。

## 五、动态元素两套参数

披风、衣袖、头发、绳索、旗面、衣摆，必须写两套：

| 人物侧 | 机位侧 |
|---|---|
| 从哪肩垂下 | 机位在哪一侧 |
| 哪边风掀起、风从哪来 | 什么角度、多远 |
| 往身体哪一侧走 | 往哪移、移到哪停 |
| 被什么动作带起 | 画面里占多大 |

**不合格**：`衣袂飘动，发丝飞扬。`——只有结果，没有受力与观察位置。

## 六、动作后补定性词

先写可见动作，再补一个定性词：
- `右手虎口扣紧刀柄，指节发白，肩背绷住，动作狠。`
- `左脚绊在门槛上，身体往前抢半步，右手扶住墙，动作狼狈。`

定性词只做一个，不叠加；不许用定性词替代关节、肌肉、承重与道具位移。

## 七、投喂参考图六标准

只约束**真正上传给模型的单张图**，不约束资产设定表。

1. 短边不低于 1024，越高越好；
2. 纯中性灰或纯白背景，不放场景、道具、文字、水印；
3. 均匀柔光，无强方向性阴影；同一角色同一套光；
4. 中性表情、不笑；
5. 一张图只有一张脸；多人同框、九宫格表情板拆开；
6. 脸与身体分开：全身图管比例与服装轮廓，脸单独一张大特写、占画面六成以上。

**张数**：同一主体≤3 张（R54）。推荐 `全身 1 张＋面部大特写 1 张＋四分之三侧或轻微低头 1 张`。不采用手册的 3–5 张最优与 8 张上限。

## 八、负面词改正面

生图资产提示词里，模型没有否定逻辑，负面词会变成正向采样。

| 不写 | 改写 |
|---|---|
| 不要模糊 | 焦点锐利，边缘清楚 |
| 不要畸形／不要多余手指 | 五官对称，每只手五根手指 |
| 不要四仰八叉 | 像学生上课一样端坐在桌前 |
| 8K／超清／大师之作 | 不写，分辨率在参数栏设置 |
| 电影感／高级感 | 先写清晰、高对比度阴影、浅景深，再补电影质感 |
| 品牌／机身型号／三脚架 | 删掉；只写长焦压缩、浅景深、背景柔化 |

**例外**：H3 分段的 `no subject looks into the lens` 等英文否定约束句是官方口径，保留不动。

## 九、远景脸崩处理

- 远景、全景不硬给正脸大特写；
- 剧情需要认脸时：脸单独出图、提高分辨率、改用近景或中近景；
- 不禁止剧情需要的远景与全景，只把「认脸」交给近景或单独面部图。

## 十、器材名只写效果

- 不写品牌、机身型号、三脚架、摄影机实体；
- 焦段可保留（R8），但补视觉结果：长焦压缩、浅景深、背景柔化、手持晃动、颗粒感；
- 若实测 `35 mm lens` 会生成实体器材，改用效果句。

## 十一、交付前 10 问

1. 复杂接触动作有没有先指定关键帧？
2. 每个动作句是不是「施力→受力→结果」？
3. 有没有用具体 IP 角色、演员、品牌名作概念？
4. 每镜是不是先写人、再写机位？
5. 动态道具写没写人物侧＋机位侧？
6. 定性词是不是跟在具体动作之后？
7. 投喂图是不是单脸、短边≥1024、纯色背景、中性表情、脸身分开、≤3 张？
8. 生图提示词有没有「不要模糊／不要畸形／不要多余手指／8K／大师级／质感拉满」？
9. 远景认脸有没有改用近景或单独面部图？
10. 器材是不是只写效果，没有品牌、机身、三脚架？
