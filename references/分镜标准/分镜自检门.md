# 镜头表自检门（六项硬检查，R70.4）

> 这道门在**写文本分镜之前、渲染之前**跑。任何一项不过，回镜头表改，改完整轮重跑，不许带着问题上分镜。

## 1. 这道门的作用

目的很单纯：把能在纸面上发现的错误，挡在花钱的步骤前面。自检是机械检查，不是审美评价。每项都必须给出 pass 或 fail，不许写"基本没问题"。

## 2. 六项检查

### 检查1 钩子密度

- **怎么查**：逐行读 `Hook Type` 列，做滑动窗口统计。
- **通过条件**：每镜都有标签（无空值）；任意连续三镜里至少出现一个 `reveal / reversal / callback`；首镜与末镜各带一个强钩（`visual-joke / reversal / reveal / suspense / tender / climax`）。
- **常见失败**：中间连续四镜都 `setup`，节奏塌成流水账；末镜写 `setup` 收尾无力。
- **修法**：把其中一镜的功能改成揭示或反转（通常是露道具／露表情／露真相），而不是硬贴一个钩子标签。

### 检查2 单镜时长

- **怎么查**：读 `Shot ID & Duration` 列。
- **通过条件**：任何一镜 ≤ 10 秒，且落在 4–10 整数（R17／R63）。
- **常见失败**：把一段完整情绪塞进 18 秒长镜；或留一个 2 秒短镜没并。
- **修法**：在动作完成点或情绪转折点切开，拆出来的秒数作为新行插入，重跑本自检；不足 4 秒的短镜在分镜层并进相邻镜，不许留到分镜视频层合并。

### 检查3 单镜重要角色数

- **怎么查**：数每镜 `Reference Anchors` 里"有动作或有台词"的角色。背景路人、不动的人形不算。
- **通过条件**：≤ 3 个。
- **常见失败**：四人同框对话。
- **修法**：拆成关系镜（两人一组）＋反应镜（听的人单独给一个表情节拍），顺带增加钩子密度。

### 检查4 空间锚继承

- **怎么查**：同一场景里有两镜以上的，逐对比较 `固定地标` 与 `光照基线`。
- **通过条件**：下一镜要么与上一镜一致，要么带明确偏移说明（例「门框随镜头左摇从右三分之一移到中央」）。
- **常见失败**：门框上一镜在左、这一镜跑到右，没人提过；主光从暖变冷无理由。
- **修法**：补偏移说明；偏移是错的就改回一致。地标位置漂移最容易被模型放大。

### 检查5 逐秒覆盖

- **怎么查**：对每一行，核对 0 秒到结束秒是否每秒都有条目，且每条五要素齐全。
- **通过条件**：无时间空档；无"继续移动""保持动作"这类没有身体／镜头／道具细节的条目；每条都写了交接。
- **常见失败**：`4–6s：两人对视`——两秒并成一条且没有要素。
- **修法**：补秒或补要素；一秒塞不下就拆镜，别删要素。

### 检查6 跨镜连贯链

- **怎么查**：只读 `Continuity Handoff` 列，从上往下连读。
- **通过条件**：读出来是一条连续画面链；没有任何一镜的起始状态与上一镜结束状态矛盾；视线、角色位置、道具状态、光照的翻转都带显式标记（`HARD CUT — 时间跳跃 2 小时`、`视线反转：Mia 从看筐改为看门`）。
- **常见失败**：上一镜筐已到 Mia 手里，下一镜又从奶奶手里递出；角色上一镜从左出画，下一镜从右侧进画。
- **修法**：改状态或加显式翻转标记。这一项挂了，分镜写出来一定是碎的。

## 3. 判定与修法示例

| 现象 | 定位到哪一项 | 处理 |
|---|---|---|
| 中段三镜都在交代信息 | 检查1 | 把中间一镜改成揭示（露关键道具或微表情） |
| 一镜 17 秒的情绪长镜 | 检查2 | 在情绪转折处切两镜，重跑自检 |
| 四人饭桌对话 | 检查3 | 拆成"两人对峙＋两人反应"三镜 |
| 厨房地标左右乱跳 | 检查4 | 补镜头运动导致的地标位移说明，或改回一致 |
| `3–5s：气氛变紧张` | 检查5 | 补身体、镜头、道具、声音、交接 |
| 筐的位置前后矛盾 | 检查6 | 改状态，或加 `HARD CUT` 标记 |

## 4. 结论输出格式

自检结论单独给一段，六项逐条 pass/fail，不合并、不省略，写在镜头表顶部（表格上方一行起）：

```
镜头表自检：镜 1-1–镜 1-12（共 12 镜）
1 钩子密度：PASS（连续三镜窗口 10 个，均含 reveal/reversal/callback；首末镜强钩 ✔）
2 单镜时长：FAIL（镜 1-7 = 18s）
3 单镜人数：PASS（最多 2 人）
4 空间锚继承：FAIL（镜 1-5→镜 1-6 门框左右位置互换，无说明）
5 逐秒覆盖：PASS
6 跨镜连贯链：PASS
结论：不通过，返回修改 镜 1-7（拆镜）、镜 1-6（补偏移说明）
```

全部通过后明确写出「自检通过」。可归档的交付必须把结论写在镜头表顶部，不能只说在聊天里。

## 5. 返工顺序

多项失败时按这个顺序修，减少重复劳动：

1. **检查2 时长** 先修——拆镜会改变镜号和后面所有引用
2. **检查3 人数** ——拆镜同样改动行结构
3. **检查4 空间锚** ——改地标与光照
4. **检查5 逐秒** ——补细节
5. **检查6 连贯链** ——最后统一顺接
6. **检查1 钩子** ——最后调节奏，因为它常靠改功能分配而不是改内容

每轮修完必须整轮重跑自检，不许只复查改过的项。
