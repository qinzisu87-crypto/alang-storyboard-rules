## 1. 表的定位

镜头表是**唯一的结构化真相**：文本分镜、分镜视频、渲染与组装顺序全部从它派生。所以它不是文学描述，而是"施工指令"——读到某一行的人或模型，不回看剧本也知道画面长什么样、怎么动、听到什么。

读写顺序恒定：先锁地标与身份 → 再填六列 → 再自检 → 再写文本分镜。顺序不可换。

---

## 2. 六列逐列定义

列名与顺序原样保留，不增不减不合并。

### 列1 `Shot ID & Duration`

镜号＋计划秒数，写 `镜 1-3 / 6s`（集号-镜序）。整数秒或半秒，全片连续不跳号。这一列是后续所有引用的坐标系（文本分镜节标题、分镜视频段号、片段文件名都复用它）。

### 列2 `Continuity Handoff`

两句话：这一镜怎么从上一镜的结束画面长出来，又怎么给下一镜开口子。可用抓手：结束画面、道具位置、视线方向、角色姿态、声音桥、情绪状态。

写法要求：**具体到可见的状态**，不许写"延续上一镜"。判定标准：把这一列从上往下逐行读，要读得出一条连续画面链，而不是一堆互不相干的片段。

### 列3 `Reference Anchors (Spatial + Identity)`

四个子字段全部必填，缺一个不合格：

- **固定地标**：用场景清单里的原名，带屏幕相对位置。例：`门框：画面右三分之一`、`中岛：画面下中`
- **角色位置（摄影机视角）**：每个在场角色的屏幕相对位置（左中右／上中下／前中后景）＋朝向＋初始姿态
- **离场角色状态**：上一镜在场、这一镜不在的角色，写清画外位置与原因；明确离场连续两镜后才可停止记录
- **光照基线**：从场景清单继承的主光／补光／轮廓光方向＋本镜调整

外加身份绑定：角色身份锁的名字（与建档时逐字一致）＋场景名；有参考图写图名与 `@图片 N` 槽号。

### 列4 `Hook Type`

受控词表里的一个短标签（见第 4 节）。作用两个：排片控钩子节奏、自检做分布统计。没有钩子的镜写 `setup`，不许留空。

### 列5 `Shot Description (Per-Second Directives)`

先给镜头层信息：景别、运镜、荷兰角设计（倾斜只用于追逐、失衡、惊吓、闹剧节拍）、表演风格、音效、负面提示，以及出片模型适配备注（见 `出片交接.md`）。然后必须带**逐秒指令子区块**，覆盖 0 秒到结束的每一秒。

本规则在这一列额外要求（与旧 R8／R9／R10 并轨）：镜头层信息里写明焦段与景别、机位高度、俯仰及理由、轴线与画左画右、固定或运动；理由只写给人看，不进提示词（R66）。

### 列6 `Audio & Dialogue Track`

这一镜的完整音频脚本，按时间顺序。与列5 的逐秒音效不是重复关系：列5 是"这一秒听到什么"，列6 是"这一镜的声音总谱"。

- **旁白**：文本＋时间区间（没有就省略）
- **对白**：台词原文＋说话人＋语气＋时间区间
- **音效**：关键音效＋锚定时间点
- **表演提示**：画外旁白秒标 `narrator-mouth-closed: true`；每句对白写表情走向、视线落点、身体动作变化

**本规则的口径（R70.6）**：台词原文只写在这一列，一句只出现一次（R14）；列5 的逐秒只写"开口／口型开合"，不抄原文；文本分镜逐格只写"谁在说"，也不抄原文。

## 3. 逐秒指令：五要素与正反例

每一秒（或不足一秒的关键节拍，写 `2.0–2.5s`）必须同时包含：

1. **动作／姿态／表情**——身体姿态、剪影、关键道具握法、视线、表情变化路径；弹性节拍显式写出挤压／拉伸／预备／过冲／跟随
2. **镜头运动**——推／拉／摇／移／手持晃动／固定／环绕
3. **空间位置**——人在哪、手里拿着什么、哪个地标在框内什么位置
4. **音频线索**——旁白／对白／音效／呼吸／静默（静默必须写"静默"，不许留空）
5. **向下一秒或下一镜的交接**——这一秒给下一步锁定了什么状态

**反例（不合格）**

```
2–3s：继续靠近，气氛紧张
```

问题：没有身体细节、没有镜头、没有道具位置、没有声音、没有交接。生成出来一定跑偏。

**正例（合格）**

```
2–3s：奶奶手臂前伸至画面中线，筐口向 Mia 倾斜约 20°，筐内苹果滚动一下；
Mia 双手前伸但指尖未接触，眉心收紧；
镜头：固定中景，视平线高度；框内：门框在右三分之一，筐在下中；
音频：筐内苹果滚动声；静默无对白；
交接：筐仍在奶奶手中，接触尚未发生（下一镜第一秒完成交接）
```

判定口诀：**逐秒指令要细到能直接画出这一格**。写不出具体身体和道具的秒，就是没想清楚。

**逐秒长度规则**：3 秒＝3 条，6 秒＝6 条，7 秒以上一秒一条；不足一秒的关键节拍只在它是本镜钩子时才额外加一条（如 `2.0–2.5s`），且不许留时间空档。

## 4. 钩子受控词表

| 标签 | 含义 | 典型用法 |
|---|---|---|
| `setup` | 建制，交代信息 | 开场铺环境、埋道具 |
| `visual-joke` | 视觉笑点 | 闹剧、反差萌 |
| `reversal` | 反转 | 预期被打破 |
| `reveal` | 揭示 | 露脸、露真相、露关键道具 |
| `callback` | 回收 | 复现前面的情绪锚或道具 |
| `suspense` | 悬念 | 门缝、背影、静默 |
| `tender` | 温情 | 对视、递东西、停留 |
| `chase` | 追逐 | 跑、躲、追 |
| `expression-beat` | 表情节拍 | 一个微表情撑住整镜 |
| `climax` | 高潮 | 冲突爆发点 |

**分布规则**：连续三镜至少一个 `reveal / reversal / callback`；首镜与末镜各带一个强钩（`visual-joke / reversal / reveal / suspense / tender / climax`）。

## 5. 完整示例行

场景：厨房。角色：Mia、奶奶。前情：奶奶从台面上拿起苹果筐要递给 Mia。

|---|---|---|---|---|---|
| 镜 1-3 / 6s | 承接上一镜结尾：奶奶弯腰从中岛拿起苹果筐，筐在画面下中静止。为下一镜开口：Mia 接住筐转身走向门框，门铃响起。 | 固定地标：门框—右三分之一，中岛—下中；角色位置：奶奶—右侧前景，朝向 Mia 偏左；Mia—左侧中景，侧身对着机位方向、不看镜头；离场角色：无；光照：顶部暖主光＋右侧冷反光；绑定：@C02 Mia、@C03 奶奶、@S01 厨房、@图片 5、@图片 6 | reveal | 景别：中景固定，收尾切近景；运镜：0–4s 固定，4–6s 缓推；荷兰角：无；表演：迪士尼式预备—过冲；负面：不出现第三个人。0–1s 奶奶弯腰双手持筐，筐底贴中岛边缘；Mia 左侧站姿，眼神下探看向筐；镜头固定中景视平线；门框右三分之一；静默；交接：筐仍在台面高度。1–2s 奶奶直起上身，手臂开始前伸，筐离台面约 15cm；Mia 视线抬起看向奶奶眼睛；镜头固定；筐到下中；布料摩擦声；交接：筐进入两人之间的空中。2–3s 奶奶手臂伸至画面中线，筐口向 Mia 倾斜 20°，苹果滚动一下；Mia 双手前伸，指尖未接触，眉心收紧；镜头固定；门框右三分之一、筐下中；苹果滚动声；交接：接触尚未发生。3–4s Mia 指尖碰到筐沿，双手合拢；奶奶手指松开，筐重心前移 5cm；镜头固定；静默；交接：筐已离手。4–5s Mia 收筐贴向胸口，身体后仰半步，眼里亮起；镜头缓推；门框移出画左三分之一；苹果轻碰声；交接：Mia 完成接管。5–6s 近景，Mia 低头看筐内，嘴角上扬；奶奶手臂落回身侧；镜头推到近景；筐占画面下三分之二；静默；交接：Mia 抬头准备转身（下一镜第一秒转身）。 | 旁白：无；对白：奶奶 3.0–3.5s「拿稳了」语气轻；音效：1–2s 布料摩擦、2–3s 苹果滚动、4–5s 苹果轻碰；表演提示：奶奶说台词时嘴部张开、下巴微收，视线从筐移到 Mia 脸上；Mia 全程无对白，视线路径为「筐→奶奶眼→筐」 |

## 6. 表级规则

- 每镜必须通过 `Continuity Handoff` 自然继承上一镜画面状态，并在**同一列**里为下一镜留口子
- 逐秒指令必须覆盖整镜首帧到末帧，不得留空档
- 表演默认夸张弹性：挤压拉伸、预备、过冲、跟随、重叠、弧线、快速姿态变化、清晰喜剧剪影
- 景别要交替：特写／大特写与其他景别穿插，避免连续同景别
- 荷兰角只设计在追逐、失衡、惊吓、闹剧节拍
- 语言只在用户明确指定时写具体语种；本规则默认照剧本原文（中文台词，`[Chinese]`），不写成"未指定"
- 有旁白或对白的镜头，每一秒都记录嘴部开合状态：画外旁白默认闭合，画面对白默认张开
- 离场角色至少跟踪一镜，连续两镜明确不在场后停止记录
- 表里不出现画面外的技术备注（"这里可能要重做"），那属于交付说明
- **集长**：一行一秒数相加必须落 220–260 秒（R37）；单镜 4–10 整数秒（R17／R63）

## 7. 字段与镜头的取舍

- 六列是下限，不是上限：可以在列5 里加子标记（如 `[BEAT]`），但不得新增列
- 一秒里塞不进五要素，说明这一秒动作设计过载：拆秒或拆镜，不要删要素
- 一镜超过 10 秒：优先在动作完成的瞬间切开，而不是平均分成两半
- 一镜超过 3 个重要角色：把群像拆成"关系镜"（两两）＋"反应镜"
