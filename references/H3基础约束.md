# 基础层：从旧技能 duanju-storyboard-to-h3 抽出来的地基

这一份只管三件事：**剧本怎么进来、视觉事实怎么立、H3 的机器边界在哪**。
凡是和《制作规则》冲突的地方，以 `references/制作规则原文.md` 为准，本文不翻案。

---

## 一、剧本怎么进来

按优先级取：

1. 对话里直接贴的剧本文本 —— 直接落盘成 `剧集/<EP>/剧本.md`，不要追问「要不要保存」。
2. 文件路径（.md / .txt / .docx）—— 读出来再用；`.docx` 走 word 技能解析，不要手工抄。
3. 小说片段 / 故事，没有场次格式 —— 先转成剧本格式，再往下走。

剧本格式（冻结）：

```markdown
## EP001-SC001 内 · 出租屋 · 夜

周野坐在床沿，手机屏幕的光照在下巴上。
[SFX] 楼道里有人拖着脚步走过

周野：几点了。
小赵：十一点四十。
```

规则：

- 场景标题 `## EPxxx-SCxxx 内/外 · 地点 · 时间`，场次连号；
- 动作写陈述句，**动作里不用冒号**，用逗号；
- 对白顶格 `角色：台词`，说话人 ≤ 8 字、不含标点与括号；
- 音效 `[SFX]` 开头；
- 不改写用户的情节与台词。要改就回头改剧本，并说明。

剧本里没有的信息不要编：

- 缺角色外观、场景材质 → 按剧中已有事实补一条最小《视觉设定.md》条目；
- 仍缺 → 分镜「参考图」写「无」，并在交付报告里点名；
- 两个关键事实互相矛盾且上下文判不出 → 停下来问。

## 二、视觉设定（连续性锁）

`视觉设定.md` 是分镜与分段的共同事实源。没有就建，有就沿用，别另起一份。

最小条目格式：

```markdown
## 人物 · 周野
- 外观：三十五岁上下，寸头，左眉尾断一截，深灰夹克内搭白 T。
- 造型状态：夹克第二颗扣子缺，袖口卷到小臂中段。
- 声音参考：输入/声音/周野.wav（男中低音，低半调，胸腔共鸣薄）
- 连续性锁：左眉尾断口必须可见；袖口卷两折，不得放下。

## 地点 · 出租屋
- 结构：单间，床靠画左墙，门在画右，床头柜上一盏黄光台灯。
- 连续性锁：台灯恒亮，墙上有两道水渍，窗右下角贴胶带。

## 道具 · 食品级塑料桶
- 外观：半透明，蓝色桶盖，桶身有刻度线与一道横向划痕。
- 连续性锁：初始水量到第三刻度线，之后只减不增。
```

「连续性锁」这一行会原样进分镜的「自然规律」与提示词，是跨镜一致性的唯一保单。

## 三、H3 的机器边界

| 项 | 值 | 对应主规则 |
|---|---|---|
| 单次时长 | 4–15 秒的**任一整数**，不是 5/10/15 三档 | R17 |
| 分镜提示词写法 | 每镜从「起幅：」起，按动作顺序连续写，不写时间码 | R13–R15 |
| 分段提示词写法 | 官方 Ref2VA 六段式（`subject_definitions`／`summary`／`retention_analysis`／`detailed_description`／`overall_soundscape`／`non_diegetic_music`），正文英文、台词包 `<d>`，人景物一律写图片中文名、不写裸标签（`retention_analysis` 行首按 R54 写 `<Subject N>（图片名：…）`）；首镜无时间码，后续镜 `At MM:SS.mmm` | R20／R20.3／R54 |
| 参考图只继承身份 | 主体定义写身份限定句与主朝向；`retention_analysis` 写朝向重排声明；机位优先侧向、禁正面平视；同一主体参考图≤3 张 | R54 |
| 投喂图与资产表分开 | 资产设定表可多角度、多表情；真正投喂的图必须单脸、短边≥1024、纯色背景、均匀柔光、中性表情、脸身分开，同一主体≤3 张 | R55.7 |
| 生图提示词不写负面词 | 不写「不要模糊／不要畸形／不要多余手指／8K／超清／大师之作／质感拉满」；H3 分段的英文否定约束句保留 | R55.8 |
| 中文语速 | 可发声约 4.1 字/秒；首帧模式常在 1.3–2.4 秒才开口 | R16 |
| 素材上限 | 图 ≤9、视频 ≤3（每段 2–15s、合计 ≤15s）、音频 ≤3、混合 ≤12 | R24.7 |
| 分辨率 | `768P` 或 `2K` | — |
| 模式 | 文生 / 首帧 / 首尾帧 / full-reference；首尾帧与 full-reference 互斥 | 备用方案见第四节 |

### 声音与口型（硬边界）

- 对白、独白、旁白的口语语言与声线写在台词行外面，逐字台词一字不改；
- 一次生成内台词只念一遍，与 R23 同义；
- 同框有不说话的正脸时，在提示词里显式写「他不说话，双唇始终闭合」，防止口型误落到近景不说话者；
- 跨镜保持同一嗓音，靠文字描述锁不住 —— 两个镜以上开口的角色，绑定《视觉设定.md》里的「声音参考」。

### 三条必须写进提示词、漏了会出事

1. **不生成字幕 / caption / 文字叠加** —— 写进 `detailed_description`：`No subtitles, captions, or text overlays are generated; only text physically present in the scene is shown.`
2. **配乐** —— 默认零配乐，`non_diegetic_music` 写 `N/A`；不许主动加 BGM（R25），只有用户当次点名才在该段写「配乐（用户指定）」并写配器/速度/节奏/动态；
3. **画内要读的文字逐字写明字形、语言、承载面与位置**，不被全局禁字指令覆盖（门后便利贴、公告栏这类必须写清）。

## 四、分段落盘格式（官方 Ref2VA 六段式）

**所有分段一律按官方 full-reference 六段式落盘**，不再分「普通模式」和「挂多图才用六段」；分镜层仍是中文连续动作白话，不受影响。

分段结构（顺序固定，六段缺一不可；六段前不许再加中文约束段）：

| 主规则里的东西 | 六段结构里的位置 |
|---|---|
| 元数据「参考图」栏的 `@图片 N` 槽、`@Cxx／@Sxx／@Pxx` | `subject_definitions`（`<Subject N>（图片名：方源）` 人物/生物、`<Picture N>（图片名：荒山巅石台全景图）` 静态帧/构图锚点、`<Video N>` 剪辑源、`<Audio N>` 音频信号；编号与槽号对映） |
| 本段一句话梗概与任务类型 | `summary`（任务类型前缀 + 谁在哪做什么） |
| 槽位用途与「不得控制」范围 | `retention_analysis`（fully_preserved／partially_preserved／attribute_transfer／weak_reference；音频 fully_copy／partially_copy／reference／weak_reference） |
| 连续动作正文（含切点） | `detailed_description`（按播放顺序；首镜 `[Shot 1]` 不写时间码，后续 `[Shot 2] At MM:SS.mmm,`；切点用 `cuts to` 等官方词；正文英文，台词用 `<d>[Language] 原文</d>` 包裹） |
| 环境底声、动作声、非语言人声 | `overall_soundscape`（不重复对白） |
| 观众配乐 | `non_diegetic_music`（默认 `N/A`；用户点名才写配器/速度/节奏/动态，不写抽象情绪词） |

落盘时仍保留段首生产元数据行（时长／场景与轴线／表演参考／参考图／标签映射／说话人）供审阅对账；六段正文是唯一贴给工具的部分。**正文引用人、场景、道具、帧图一律写 R20.3 的图片中文名，不写裸 `<Subject N>`／`<Picture N>`。**核对：逐字台词未变、时长未变、切点数与镜数一致、图片中文名与定义行一致、`(Sx)` 六段之间一致。

## 五、别再踩的坑（旧技能遗留，已换成新格式的说法）

- **时长**：分镜与分段两边必须逐镜相等，不许暗改；时长只写在字段里，不写进提示词。
- **台词引文**：四字以上中文必须逐字来自剧本，整条提示词里只出现一次。
- **参考图**：槽号是计划不是图。写了 `@图片 N` 就代表「这儿要挂第 N 张」，换图只换文件不换号；不要拿图片提示词当图用。
- **别越界**：分镜不改剧本情节，分段不改分镜边界；要改就回头改上游文件并说明。
- **段落边界**：一段一次生成，段与段靠 R24 对齐，不靠后期剪。
- **配乐**：默认零配乐，`non_diegetic_music` 写 `N/A`。任何「加点氛围」「垫一层音乐」的念头都不许落地；用户当次点名才写，并在元数据行标「配乐（用户指定）」。
