**R1 必须能直接投产。**

## 二、流程与文件结构

``
<项目目录>/
├── 制作规则.md                     # 本文件
└── 剧集/<EP>/
    ├── 剧本.md                     # 场次 + 场景站位 + 台词 + 声音设定 + 表演总则
    ├── 人物资产-设定卡.md            # 人物资产一：只放 A1 人物设定卡（左头像＋右三具无头身形），R75
    ├── 人物资产-面部与服装.md        # 人物资产二：放 A2 面部半身特写＋A3 服装三视图，R75
├── 人物资产-立绘.md              # 人物资产三：每角色一张 A4 人物立绘（单人全身站姿、竖 3:4、浅灰或纯白棚底），R80
├── 短剧镜头全典.md               # 69 条镜头：名称／档位／作用／画面；写列5 必须照画面栏落到当前这一镜，R82
    ├── 资产提示词.md                # 人物 C / 场景 S / 道具 P 编号 + 生图提示词，不写进剧本正文
    ├── 分镜/镜头表.md               # 六列镜头信息表＋六项自检结论
├── 分镜/文本分镜.md             # 一镜一节、十一字段、逐格四象限
    └── 分镜视频.md            # 相邻镜打包成 4–10 秒生成段，官方 Ref2VA 六段式

顺序不可颠倒，剧本台词验收通过后才进分镜，分镜验收通过后才进分段。**一次只做一集，一集按 4 分钟（240 秒，落 220–260 秒）配戏，集与集靠「结尾状态／下一集承接」两段接上（R37）。**

**R37 一集就是 4 分钟；一次只做一集；集与集必须接得上（硬约束）。**（2026-11-16 增补）

1. **一次一集**。每次请求只产出 **1 集**（`剧集/<EP>/` 一套：剧本、资产、分镜、分段提示词）。不连做两集、不批量出多集；还要下一集就重新起一轮，按集分开交付。
2. **4 分钟口径**。一集总时长按 **240 秒**做，落在 **220–260 秒**（4 分钟内，容 ±20 秒）。落地办法：按 4–10 秒一个生成段估，约 18–30 段；写完把分段「时长」相加，与分镜合计相等，且总时长必须落在这个区间，偏了回头删并或补戏，不许标称 4 分钟、实际 2 分钟。
3. **一集要有完整弧**：开局有由头（承接上一集或事件起点）、中段有推进与一次转折、结尾留一个未解（下集要接的钩子），按 4 分钟配比铺开：0:00–1:00 起势、1:00–3:00 推进与转折、3:00–4:00 收束并留钩。
4. **结尾状态**。剧本末尾固定写 `## 本集结尾状态`：结尾时间点、每个在场人物的位置／动作／情绪／知道什么／手里拿着什么、还有什么没解决。
5. **下集承接**。剧本末尾再写 `## 下一集承接`：下一集从哪个时间点、哪个地点、谁的第一句话/动作接上；跨集必须沿用的 C／S／P 编号、图槽号、基础声、未结线索逐条列出。下一集写剧本时先照抄上一集的这两段再动笔，不许另起炉灶。
6. **续集先核对**。开新一集时先 `Read` 上一集 `剧本.md` 的结尾状态与承接段、上一集 `分镜/文本分镜.md` 的末镜，再写本集；本集第 1 场的「场景站位」与首镜起幅必须能接上上一集末帧。


写文件注意，大文件分块写入；不要用会吞掉「提示词」栏之后内容的切分脚本（本集踩过两次，丢了场标题与站位段）。

**R36 一次写不完就分批跑；续跑沿用上一轮的选择与资产，确认之后才进分镜（硬约束）。**（2026-11-16 增补）

1. **分批**。一部剧的剧本、资产、分镜、提示词一次生成不完时，按「先剧本＋资产 → 等确认 → 再分镜＋分段提示词」切成多轮。每轮开头写清范围与进度，例 `本轮：SC001–SC008 剧本＋C01–C04 资产（其余待续）`；已写完的部分先落盘交付，不留半截占位、不写「此处略」。
2. **用户说「继续」就接着写**。续跑只补没写完的：场次 ID、C／S／P 编号、图槽号、基础声一律接上一轮，只顺延、不重排、不回收；已经交付的内容不重写、不改口径。
3. **选择沿用，不重问**。参考画风（一集最多两套编号：人物一套、场景道具一套）、道具固定一件一张白底图（人物与场景固定张数，三类都无层可选）、资产层范围，全部沿用第一轮定下的；第二轮及以后不再问第二遍，也不许换画风、换层写法。
4. **能用的资产直接复制**。上一轮已写好的角色、场景、道具条目，编号与提示词（含 `参考画风 REF-900（取其质感，形象按本剧）` 尾巴与图槽号）原样复制到新一集的文件里；新增条目从现有最大号往后顺延。
5. **换装只改衣服，脸不动**。角色在本轮换了服装，重出的是服装与全身提示词，**脸必须与上一轮完全一致**——脸型、五官、肤色、发色、瞳色、疤痕这类识别特征一个不改，提示词里写死 `同一张脸，五官与上一轮一致`；只换衣物、配饰与版型。只有剧情明写换脸／易容／面具时才允许变脸，并在该场写明依据。
6. **确认门**。剧本（或选跳过后等价的切场结果）与资产写完先交用户看，**等用户明确确认（「可以」「过」「出分镜」）之后才写分镜与分段提示词**；没确认不许往下走，也不许先写几镜试探。

## 三、剧本层

**R3 画面怎么动要写清。**
从哪进、脚怎么落、眼睛先看哪、手在做什么、重心怎么移，都要落地。

**R4 动作写到关节与肌肉，明确「哪只手、怎么抬」。**
「抬手」不合格。合格写法，「右手从大腿外侧起，肘先屈、小臂抬到胸口高，腕外旋，掌心转向内，拇指与食指张开去夹」。左右手、顺序、力度、承重点都要指定。

**R5 先写情绪，再写这份情绪对应的身体。**
情绪是第一层，一句写清这是什么情绪、几成强度、对着谁或对什么事，例，「被压住的慌，七成，冲着门外那串脚步声」。第二层才是它在这具身体上长成的样子，哪块肌肉动、动多少、何时动、动完停在哪，例，眉心竖纹收拢、上眼睑抬高两毫米、下唇内收露出半颗上门牙、咬肌鼓起又松开、喉结滚一次把话咽回去。
**两层都要写，顺序不能反。** 只写情绪，AI 拍不出来；只写肌肉，等于没有依据。
**情绪词本身是必写项，不是省掉不写**（2026-11-16 明确）：人的情绪绝大多数是身体语言给的，但必须先有名分——先写情绪词（什么情绪、几成、冲着谁），再把这份情绪落到肌肉与肢体上。**剧本、分镜、分段提示词三层都按这个顺序写**：剧本的场次动作与台词前、分镜的「表情」栏、分段 `detailed_description` 动作句，都要「情绪词＋身体反应」成对出现，不许只剩动作流水账。

**R6 语气单独写一行。**
每句台词前写发声方式与语气（音量、语速、尾音走向、气声比例、停顿位置）；不要塞进说话人标签里，标签超过 8 字或带标点会让台词解析漏检。

**R7 一人一种基础声，情绪只做调制。**
先定固定基础声（音高、共鸣位置、音色、默认音量、默认语速、句尾处理、换气方式），任何情绪都在**这条基础声上加减**，不换底。本剧五档，后续集沿用：
- **V1 周野**，男中低音、低半调、胸腔共鸣薄、带沙、音量五成、每秒 3–4 字、句尾下压、浅换气。
- **V1-VO 周野内心**，在 V1 上去胸腔共鸣、气声一半、音量再降两成、语速更慢。
- **V2 小赵**，男中高音、口腔前部共鸣、明亮带脆、音量八成、每秒 5–6 字、尾音上挑半调、字尾鼻音。
- **V3 老陈**，低音沙哑、气多声少。
- **V4 电视播报**，中性播音腔、音高居中、语速均匀、句尾平落、零情绪。
新角色进场，先补一条基础声再写台词。

**R32 任何小说都能直接开跑，不必先有剧本。**（2026-11-16 增补）
小说、网文、整本书、某一章或一段故事都算输入。收到后先按下面五条落成 `剧本.md`，再照常走三层；不许因为「没有场次格式」就停下反问，也不许要求用户先自己改成剧本。

1. **切场**。一段叙述群＝一场；地点、时间、在场人一变就新开一场。标题固定 `## EPxxx-SCxxx 内/外 · 地点 · 时间`；EP 编号用户给了就沿用，没给就从 `EP001` 起，场次号在集内连号。
2. **叙述转动作**。小说里的描写句改成可拍的动作陈述句：谁、在哪、朝哪、做什么；动作里不用冒号、用逗号；拍不出来的形容（「气氛压抑」这类）改写成具体可见的状态，改不出来就落到表情栏或场景材质里。
3. **对白转台词**。引号里的说话原样落成 `角色：台词`，不改字、不删语气词；说话人超过 8 字或带标点、括号的，缩成名字再写。
4. **心理与旁白**。第一人称、第三人称的心理描写**不做旁白念白**：转成 `V1-VO` 内心（不张嘴、气声走鼻腔与齿缝），或写进该镜「表情」「动作先后」栏当依据。叙述性旁白一律不进提示词。
5. **不编**。小说没写的人物、地点、道具、关系一律不加；缺外观、缺材质按最小《视觉设定.md》条目补，仍缺就在该镜「参考图」写「无」并在交付报告里点名。**整本小说按集切**：每集先写一句「本集讲什么」，再落场次；跨集的 C/S/P 编号、基础声、参考图槽号照旧顺延。

**R33 小说一进来，先问一句：先生剧本，还是跳过剧本。**（2026-11-16 增补）
只问这一个二选一，不夹带别的问题；**题材先定（R38），题材没定不问这一句**；用户没答之前不开跑。

1. **先生剧本（默认）**：按 R32 落 `剧集/<EP>/剧本.md`，剧本验收过了再出资产与分镜。
2. **跳过剧本**：本集不出 `剧本.md`，用 R32 的切场与台词结果直接写 `资产提示词.md`、人物／场景资产与 `分镜/镜头表.md`、`分镜/文本分镜.md`。**分镜场标题的「来源」改写成小说位置**（`来源：第 3 章 第 2 段`），不写 `EPxxx-SCxxx`；其余八项照旧。
3. 两种方式都不许改情节、不许编人物、不许因为跳过就漏掉台词的逐字原话与基础声；跳过只省掉「供审阅的剧本文件」，不省转换工作。
4. 用户已经说「直接出分镜」「不用先看剧本」的，视为选了跳过，不再重复问。
5. 自检：跳过时脚本加 `--skip-script`，`剧本.md` 那几项按「已跳过」处理，其余全查（含分镜场标题必须带来源）。

**R38 小说一进来，先在这 21 个题材里选一个（硬约束）。**（2026-11-16 增补）

21 个题材分四大类：**幻想 5**（玄幻修仙、西幻魔法、星际机甲、系统无限流、末日废土）、**古代 6**（穿越重生、宫斗、宅斗、权谋朝堂、武侠江湖、种田经商）、**现代 8**（都市逆袭、总裁甜宠、家庭伦理、重生复仇、职场商战、年代文、娱乐圈、大学校园青春）、**类型片 2**（悬疑刑侦、民俗怪谈）。逐条节奏、对白字数、台词口径、进度字段与尺度见 `references/题材规范.md`。

1. **问两轮，一轮只问一件事**。第一轮只问四大类（回序号、类名或题材名都行）；第二轮只列该类的细分（最多 8 个，一次列完）。**不许合并成一张多选题，不许替用户选。**
2. **直达要核对**。用户直接报题材名或代号（如「宫斗」「T07」）＝跳过第一轮，但必须核对在本表里存在；不在就让他重选，**不许拿相近题材顶替**。
3. **落盘**。`剧本.md` 标题下一行写 `题材：T07 宫斗`；跳过剧本（R33）时写进 `分镜/镜头表.md` 标题下一行。跨集沿用同一行；换题材等于换项目。
4. **按题材写，不按模板套**。每集 4–7 场；台词语速按每秒约 4 字；对白字数按该题材下限走，不到就补一轮交锋或一段完整对话，**不许只加描写充数**；开头 3 秒要有动作或强台词，结尾钩子写成一个画面或一句台词；本集进度按该题材字段写（与 R37 的「本集结尾状态」并写）。
5. **只加不改**。题材只管「写什么、怎么配戏、尺度到哪」，**不改 R1–R37 任何一条**：段长 4–10 秒、一集 220–260 秒、六列、连续动作提示词（不写时间码）、台词只说一遍、独白不张嘴、不配乐、多人排队、场景与道具的 A／B 资产、只出提示词、参考图画风锁，全部照旧。题材与既有规则冲突时以既有规则为准，并在交付报告里点名。
6. **顺序固定**：题材（R38）→ 先生剧本还是跳过（R33）→ 剧本＋资产 → 用户确认（R36）→ 分镜＋分段。题材没定，不许开写。

**R39 幻想类有特效，剧本要写明，分镜要写到能拍：形态、光源、起、中、收，五件事一件不许缺。**（2026-11-16 增补）

范围：幻想五类（T01 玄幻修仙、T02 西幻魔法、T03 星际机甲、T04 系统无限流、T05 末日废土）画面里出现特效就必须写；其他题材出现特效（法术、爆炸、能量、异象、怪物变化）同样照此写。没有特效的集不硬造。

1. **剧本层**：每场特效单独一行，以 `[VFX]` 开头，按 `名称｜形态｜光源｜起｜中｜收` 写，不塞进台词、不并进普通动作句。一条特效一行，不在一行里堆两种特效。
   例：`[VFX] 青灰灵气｜半透明、边缘带细碎光粒、内部有缓慢流动的纹路｜光源：自掌心向外，照亮周野半张脸与脚前十厘米地面，影子往画右偏｜起：右掌虎口先亮一点，光沿小臂爬到肘，0.6 秒内张开成直径半米的球｜中：球面起伏，光粒被吸向中心，亮度上抬一档，持续 2 秒｜收：从外沿向内塌，剩一圈余光贴掌心，两秒后熄灭，指缝留一缕青烟`。
2. **分镜层**：同一特效写进三处——「动作」栏开头 `特效：<名称>｜形态…｜光源…｜起…｜中…｜收…`；「自然规律」补它的光、热、风、受力与投影；「动作先后」用 ①②③ 拆出先亮哪、再长到哪、何时塌；「提示词」按动作顺序写清起、中、收，**起与收各写成一个可见阶段**，不许只在中间闪一下。
3. **五件事的标准**：形态（颜色／材质／透明度／体积／边缘／内部结构）、光源与照射范围（照亮谁的脸、地上影子往哪偏）、起（从哪个部位或物体生出、谁触发、几拍到位）、中（持续几秒、形状与亮度怎么变、伴随的风热与受力）、收（怎么衰减、散成什么、留下什么、镜头停在哪一帧）。
4. **不许含糊**：「炫酷」「特效拉满」「光效强烈」「气势磅礴」一律不合格；每个形容词都要落到可见、可数的参数上。
5. **与人物和镜头绑定**：特效属于谁、从哪只手或哪个部位出、镜头跟着特效推还是留给人的反应，必须写清；特效不许遮住脸，口型镜里更不许盖住嘴。
6. **跨段**：特效跨段时，段尾停在稳定态或收束前一拍，下一段起幅句承接同一形态、同一亮度、同一位置（R24）；一段之内不许特效凭空出现或凭空消失。
7. **系统类**：系统特效只做光幕、纹路、进度环这类图形，**不生成可读文字**（全片不生成字幕、caption、文字叠加）；系统话语仍走 `系统（画外）`。
8. **只加不改**：特效仍是画面描述，六列、连续动作提示词（不写时间码）、台词只说一遍、独白不张嘴、不配乐、只出提示词，全部照旧。

**R40 光影只照原文：原文写了光影就必须写进剧本、分镜和分段提示词，原文没写就不补。**（2026-11-16 增补）

1. **什么叫原文写了**：出现光位、明暗、影子、逆光、侧光、顶光、窗光、月光、烛火、灯光、火光、闪电、屏幕光、色温、光变这类描述，就算写了；凡是原文写到的场次，剧本、分镜与该集分段提示词三层都必须把光影落到位，不许漏。
2. **原文没写就不写**：不许新增光源、不许凭气氛加「夕阳」「霓虹」「暖光」「冷调」；没有光影描写的场次，按原文的昼夜与室内外事实陈述，不加戏剧性打光。
3. **剧本层**：每场在「场景站位」行下面另起一行 `[LIGHT] 光源｜方向｜强度／色温｜落点｜变化`，一行一场，不并进台词、不并进普通动作句。
   例：`[LIGHT] 门缝漏光｜方向：从门后向画左斜射，与门框成 30°｜强度／色温：弱、3200K 暖黄｜落点：切在周野右脸颊与门把手，地面拉出一道窄长影子｜变化：0:06 门开大后亮度升一档，影子拉长到床沿`。
4. **分镜层**：「自然规律」写光源方位、色温、明暗比、投影方向与边缘软硬；「动作」写走位穿过光区时的明暗变化（脸先进亮处、手后出影子）；「提示词」按动作顺序写，**光变写清起收阶段**，起幅第一句先写清光位。
5. **分镜视频层**：元数据「场景与轴线」写本节光位、色温与承接（照上一段末帧）；`detailed_description` 按动作顺序写光，起幅第一句先写光位，光变写清起收阶段；跨段不许换方向、换色温、凭空变亮变暗（接 R24）。原文写的是烛火将熄，就一段比一段弱，不许下一段又亮回来。
6. **与 R39 的关系**：特效自发光时，必须同时写它照到谁、影子往哪偏；特效光与场景光叠加，写明以哪一层为主、谁被压暗。
7. **不许**：只写「光线昏暗」「光影交错」「氛围感」这类不落参数的词；不许用光影遮脸、遮嘴、挡住正在说台词的人；不许为了光影好看改站位与轴线。
8. **只加不改**：六列、连续动作提示词（不写时间码）、分段 Ref2VA 六段式、段长 4–10 秒（R17）、一集 220–260 秒（R37）、台词只说一遍、不配乐，全部照旧。

**R78 道具资产每件只出一张「道具资产图」：单件完整入画、默认纯白无缝背景，不再分 A／B、不问层（2026-11-28 增补，重写 R41 的 A／B 六项出图口径）。**（原 R41 的「A＝主视觉＋三视图＋状态变化、B＝局部细节＋颜色材质＋使用交互」作废）

1. **一图一件**：每件道具一条提示词、一张图、一个图槽；整件完整入画、单件居中、四角留白、无手、无其他物体遮挡、无投影压画面；长件可斜置 30–45°（剑、伞、幡），不裁切。
2. **默认白底**：每条写 `纯白无缝背景`；用户明确指定别的底色（浅灰、深色等）才改，并在这一条写清，同批道具同一底色。
3. **只画主状态**：正常／激活／使用／损坏／修复里只画剧情真正用到的那一个状态；其余状态与变化节点写进文字档案，不另出图。
4. **以下不再出图**：正／侧／背三视图、局部细节拼图、材质板、人物握持与使用交互图、多状态并列图；需要交代的内容并进这一张的字面要求与文字档案。

**R83 连续动作链可以给 4 秒（硬约束，2026-11-28 增补，修订 R81 适用范围；镜长仍照 R79）**

**R54 参考生视频的视线与朝向控制。**（2026-11-18 增补，2026-11-24 按模板改措辞；完整条款见 `references/视线与朝向控制规范.md`）

参考图只继承身份（五官、骨相、发型、服装、体态、伤损细节），不继承正脸、头部朝向、视线与肢体姿态；画面信息由分镜重新指定。十条同时生效：

1. **身份继承**：每个 `<Subject N>` 定义句写 `The reference supplies ... only; ... follow the shot description.`；人物写 `facial identity, hair and costume only; pose, head angle and eyeline follow the shot description.`；图片名用参考图真实文件名主干，不得简写；同一主体全身、面部、细节图归一个 Subject。
2. **朝向预声明**：主体定义写 `main orientation: ...`（`standing on the left..., facing right`／`three-quarter to camera`／`back to camera`），与分镜一致；同角色每镜重写，不沿用上一镜。

6. **机位与构图**：优先 `over-the-shoulder`／`three-quarter`／`profile`／`back-to-camera`；正面平视只给空镜与环境；避免「平视＋正面」，改用 `slight low angle`／`slight high angle`；正打镜头前景放肩部／刀柄／岩石边缘遮挡；一段三分镜正面机位不超过一个。

9. **用词固定**：视线只用 `eyeline`、`gaze`、`pupils`、`head angle`，不同义替换、不混用。
10. **自检**：按 `references/视线与朝向控制规范.md` 第 8 节 10 项逐条核对，任一不满足即退回。

**R55 提示词方法论吸收。**（2026-11-24 增补，来源《AI视频提示词方法手册》；只吸收与 H3 不冲突的部分，不改变 R1–R54。以下十条写法同时生效，第 11 条是自检）

1. **关键帧前置**：接触、拥抱、比武、兵器咬合、多人身体交叠，以及训练素材里少见的非标准姿势，先在分镜指定一张关键帧（首帧／中段／尾帧），挂 `@图片 N`，再写分段；普通走、坐、说、看不必强制。关键帧只定姿势与构图，不复制参考图的正面取向（R54）。
2. **动作写成因果链**：每个动作句必须有「谁施力 → 作用到谁／什么 → 出现什么可见结果」，不许三条并列属性各写各的。例：「月光落地，他踩过，鞋底把光切断」；不写「月亮很亮、他站着、地上有反光」。R50 的七件事照旧，因果句只改句内组织，不减少信息。
3. **概念替代形容词**：形容词堆不出画面时，换成模型认识的通用视觉概念，或「具体动作＋一个定性词」。概念必须可拍、通用；禁止用具体 IP 角色、演员、导演、画师、品牌名作比（不写「像哪吒拉弓」「像某某电影」），避免本尊或品牌物进画面。情绪词仍按 R5 必写，不被概念包替代。
4. **人先定死，镜头后补**：每镜先写人站哪、朝哪、起始动作与承重点，再写机位怎么动；机位运动不许改人物身份、朝向与视线。参考图不提供朝向（R54）。
5. **动态元素两套参数**：披风、衣袖、头发、绳索、旗面这类动态物，先写人物侧（从哪肩垂、哪边风掀起、往哪边身体走），再写机位侧（机位在哪、什么角度、多远、往哪移）；不许只写「衣袂飘动」「发丝飞扬」。
6. **动作后补定性词**：具体动作、关节、肌肉、承重写完之后，才允许补一个定性词（狠、狼狈、潇洒、僵硬）；定性词不替代动作细节，不许只写「动作潇洒」「电影感拉满」。
7. **投喂参考图六标准**：只约束喂给模型的单张参考图，不约束资产设定表与表情清单——短边不低于 1024；纯中性灰或纯白背景；均匀柔光、无强方向阴影；中性表情、不笑；一张图只有一张脸；脸与身体分开（全身图管比例与服装轮廓，脸单独一张大特写、占画面六成以上）。同一主体投喂图合计仍不超过 3 张（R54），不采用手册的 3–5 张最优与 8 张上限。
8. **负面词改正面**：生图资产提示词里不写画面负面词——不写「不要模糊／不要畸形／不要多余手指」，改写「焦点锐利／五官对称／每只手五根手指」；不写「8K／超清／大师之作／质感拉满」，分辨率在参数栏设置。H3 分段里的 `No subject looks into the lens` 等英文否定约束句是官方口径，保留不动，不适用本条。
9. **远景脸崩处理**：远景、全景不硬给正脸大特写；剧情需要认脸时，脸单独出图、提高分辨率、改用近景或中近景；不禁止剧情需要的远景与全景。
10. **器材名只写效果**：不写品牌、机身型号、三脚架等实体器材名；焦段可保留（R8），但只写视觉结果（长焦压缩、浅景深、背景柔化）。若实测 `35 mm lens` 会生成实体器材，改用效果句；器材与质感词一律先翻译成画面效果，不凭空加实物。
11. **自检**：第 10 节第 31 条按本条 10 项逐条核对；生图资产提示词命中负面词、8K、大师之作，或分段里用具体 IP 角色名作比，即退回重写。

**R56 分段写法以 `references/分镜视频模板.md` 为唯一准绳。**（2026-11-24 增补，优先级最高）

该模板由用户提供的 EP001 反推样本固化而来。格式与用语逐字照它，剧情内容逐集替换；R20／R51／R52／R53／R54 中与本节冲突的措辞，以本节为准。

1. **文件头**：`# EPxxx 分镜视频`；下一行 `> 本集：N 段，合计 S 秒。题材 Txx <题材名>。画风 REF-xxx：<画风锁>`；不写「反推样本」。
2. **元数据六行**：`*` 行，行间空行；`时长：N 秒`；`场景与轴线` 写场名、光位、左右站位、机位工作侧、后景；`参考图` 只写 `@图片 N`；`标签映射` 只写 `Subject N 名字`；`说话人` 写 `① (S1) 名字 → ② (S2) 名字`。不写 `@Cxx／@Sxx／@Pxx`。
3. **六段排版**：六个字段行各缩进两个空格；字段名纯小写加下划线；六段前没有中文约束段，也没有 `###`。
4. **`subject_definitions` 固定公式**：`<Subject N>（图片名：中文名）: The reference supplies <职责> only; <姿态／机位从句> follow the shot description. main orientation: <本段主朝向>.` 人物＝`facial identity, hair and costume only`；群体＝`costume and silhouette only`；场景＝`environment layout and lighting only; camera angle and view direction follow the shot description`；道具＝`object shape and material only; pose, head angle and eyeline follow the shot description`。不写长段五官、服装、材质描述。
5. **`summary` 一句**：以 `[reference generation]` 开头（有具体帧锚点才换 `[keyframe completion]`），后接 `One shot ...` 一句英文（R63 一镜一段）；不写第二段，不列参考关系清单。
6. **`retention_analysis` 固定句**：每个 Subject 一行，`<Subject N>（图片名：中文名）: fully_preserved；head angle and eyeline are reblocked per shot; reference frontal orientation is not preserved.` 群演／远景可 `weak_reference`；场景与道具也照同一句，不另换措辞。
7. **`detailed_description` 固定开头**：第一句 `The scene is <场景>. An outside witness records <一句英文场景与事件>. No subject looks into the lens, and no subject adopts the frontal gaze of the reference sheets; everyone is held in profile or three-quarter view, pupils directed off frame at the opponent.` 第二句 `Only the character who is speaking moves their lips; the rest keep lips closed.` 不写画风句、不写 `Camera:` 标签、不写中文整句。
8. **镜头行（R63 一镜一段）**：每段只有一个 `[Shot 1] <景别>, <机位>: ...`，不写时间码；**不再有 `[Shot 2]` 起的 `At MM:SS.mmm` 切点**，要切镜就另加一镜、另起一段；段「时长」＝该镜「镜长」，两者 4–10 秒整数。
9. **台词块后置**：所有台词放在全部镜头之后，每句一行、缩进两个空格：`(Sx) 角色：[Chinese] 原文`；同一角色连续多句逐句换行；不用 `<d>`、不写 `says`。画外／独白 `(Sx) 角色（VO 不张嘴）：[Chinese] 原文`。
10. **声音两段**：`overall_soundscape` 一句英文环境声、动作声、非语言人声；`non_diegetic_music` 固定 `N/A`，用户当次点名配乐才写。
11. **字数**：不套 350–500；按模板密度写，通常 150–350 英文词，台词密集段按发声时间排满；动作、表情、视线、道具、光不许比同镜分镜少。
12. **冲突处理**：旧 `<d>` 台词、`The camera observes as an outside witness...` 固定句、`for this segment` 保留句、分段 `@Cxx` 要求全部作废；以本节与 `references/分镜视频模板.md` 为准。

## 四、分镜层（单镜）

**R8 「拍摄手法」写清怎么拍，每条带理由。**
必含，焦段与景别 → 机位高度 → 俯仰及理由 → 轴线与画面左右（谁在画左、谁在画右、机位在哪一侧） → 固定或运动、动什么、动到哪 → 镜长依据。理由不许省，略仰＝被压、略俯＝看手、平视＝同行；写不出理由的机位就是错机位。

**R9 「动作先后」用 ①②③ 排顺序。**
先哪步、后哪步、力从哪传到哪、哪一下承重、哪一下卸力。两个动作不许写在同一拍，必须拆先后。

**R10 「自然规律」写**这一镜必须成立的物理与生理事实**。**
重力、摩擦、惯性、液体、光、体温、呼吸、瞳孔、肌肉疲劳，写成可核对的事实，不写形容词。

**R11 参考图槽按 R2 挂句子里。**

**R12 机位与方向要符合观众的正常逻辑。**七条：
1. 一场只在一侧工作，不越 180 度轴；
2. 视线相反的人配对剪；
3. 出入画方向接得住（上一镜往画左走，下一镜不能突然往画右走）；
4. 高度有理由；
5. 特写之后给空间出口；
6. 主观镜单独标，不与实景共享轴线；
7. 特写接特写，机位夹角不小于 30 度。

## 五、提示词写法

**R13 分镜提示词不写时间码，按动作顺序连续写。**（分镜视频层不套本条，按官方 Ref2VA 六段与切点写）
``
起幅：谁在哪、面朝哪、画面左右谁在左谁在右，机位与景别
一句动作：先发生什么，写到关节与肌肉
角色（情绪＋语速＋音量＋尾音＋音色不变）：台词
切：新画面
``
不写 `0:00`、`0:02` 这类时间码，也不按秒拆行。先写动作，台词发生在哪一步，就把台词行插在那一步之后。动作句不用冒号，避免被当成台词。

**R14 台词只写一次，按说话先后另起一行。**
一镜内先写动作，台词只写在发生的那一步，不提前、不复述。同一时刻只有一个人说话，一句台词占一行。

**R15 每个分镜镜头各自从「起幅：」起。**
不做全片连续时间轴，不累计秒数；同一段内的第二个镜头用 `切：` 开头，不写任何秒数。段与段之间也不靠时间码对齐，靠 R24 的动作接缝对齐。分镜视频层不是这个写法：按官方 Ref2VA，首镜 `[Shot 1]`、后续 `[Shot 2] At MM:SS.mmm`。

## 六、镜长与 H3 区间

**R16 普通动作＝1 秒；两个动作＝2 秒。**
眨眼、按键、抬手、拧一下，都是 1 秒。连续变换或连贯动作（走完一段、弯腰提两提、写满四行）按实际完成所需秒数，不硬套。
有台词或独白的镜头以发声时间为准，其中的普通动作仍按 1 秒核。

**R17 每条生成段落进 H3 的 4–10 秒，整数秒；一条段落＝分镜的一镜（R63）。上限 10 秒、下限 4 秒为硬约束（R79）。**
- 一段只装一个镜头，段长＝那一镜的镜长，所以镜长也必须落 4–10 秒整数；
- 分镜里不足 4 秒的短镜（打斗 1–2 秒、反应与插入特写 2–3 秒）在分镜层就并进相邻镜，合成一个 4–6 秒的连续镜，不留到分镜视频层合并；
- 长镜（超过 10 秒的报账、数水独白）在分镜层就拆开，拆成两镜各 5–8 秒；**任何一镜到 10 秒为止，不许超**；
- 本集已生成版本按 1–10 秒排（73 镜 / 235 秒 / 20 段），按「不回溯条款」不改；**新集按本节排**。

## 七、分段（官方 Ref2VA 六段式）

**R18 一段一镜，段内不许出现第二个 `[Shot]`（R63）。**
每段 `detailed_description` 只有一个 `[Shot 1]`，`[Shot 1]` 不写时间码；**不许写 `[Shot 2]` 起的 `At MM:SS.mmm` 切点，也不许用 `cuts to / transitions to / changes to / switches to` 在同一段里换机位**——要切镜就是分镜里另一镜、另一段（加镜就加段）。段内仍可写机位运动（推、拉、摇、跟、升降）替代切镜，但只允许一次连续运动，不许中途换机位当切镜。接缝落在动作能接住的地方，不许腰斩镜头。

**R19 相邻段必须连贯。**
方向、视线、持物、身体状态在段与段之间接得上：同场同机位方向写 `hand-off seamless`（A 无缝接），跨场或换轴线写 `Transition out:`／`Transition in:` 同名（B 显式转场，R60），并在 `Entry:` 写明 hard cut 到新场名与新朝向，不沿用上一场轴线。

**R20 每段逐字照 `references/分镜视频模板.md` 落盘（R56），六段顺序固定，缺一不可。**

段首保留 `*` 元数据六行（供审阅对账，不贴给工具）：`时长／场景与轴线／表演参考／参考图／标签映射／说话人`。其后是唯一贴给工具的六段正文；**六段之前不许再加中文约束段**，六个字段行各缩进两个空格，写成 `subject_definitions:` 这种纯小写字段行，不用 `###`。

1. `subject_definitions`：定义 `<Subject N>`（人物／群体／场景／道具）、`<Picture N>`（只限首帧／关键帧／尾帧／构图锚点／故事板）、`<Video N>`（剪辑源／延续起点／时间结构）、`<Audio N>`（音频信号）；`<Video N>` 与 `<Audio N>` 各自独立编号，不配对。**人物、场景、道具的参考图只作主体来源时，写进对应 `<Subject N>` 定义里，不单开 `<Picture N>`。**只定义本段实际用到的标签。**每条定义写 `<Subject N>（图片名：<中文名>）: The reference supplies <职责> only; <姿态／机位从句> follow the shot description. main orientation: ...`；正文一律用这个名字，不写裸标签（R20.3）。**
2. `summary`：**必须以方括号任务类型开头**（`[keyframe completion]`／`[reference generation]`／`[video editing]`／`[video continuation]`／`[audio reuse]`／`[audio reference]`，多关系用 ` + ` 组合）＋一句英文 `One shot ...`（R63：一镜一段）；人、景、物写图片中文名。没有视频输入不写 `video continuation`、不定义 `<Video N>`。
3. `retention_analysis`：每个 Subject 一行，`<Subject N>（图片名：中文名）: fully_preserved；head angle and eyeline are reblocked per shot; reference frontal orientation is not preserved.` 可见参考按 R54 只用 `fully_preserved`／`weak_reference` 两档；音频参考：`fully_copy`／`partially_copy`／`reference`／`weak_reference`。
4. `detailed_description`：固定第一句 `The scene is <场景>. An outside witness records ... No subject looks into the lens, and no subject adopts the frontal gaze of the reference sheets; everyone is held in profile or three-quarter view, pupils directed off frame at the opponent.`；第二句 `Only the character who is speaking moves their lips; the rest keep lips closed.`；再写 `Entry:` 与唯一的 `[Shot 1]` 块与 `Exit:`（R63：一段一镜、不写时间码、不出现后续 `[Shot N]`）；每镜写构图、主体外观位置、环境光、动作与状态变化、机位、当前声音、参考生效点；人、景、物写图片中文名；通常 150–350 英文词。
5. `overall_soundscape`：环境声、动作声、非语言人声一句英文；台词与画内音乐不在此重复。
6. `non_diegetic_music`：观众配乐 1–3 句，只写配器／速度／节奏／动态，禁抽象情绪词；默认无配乐写 `N/A`。

**R20.1 机位写在镜头行冒号前，用自然句。** 可用 `fixed camera`／`handheld sway, low angle`／`tracking laterally`／`over-the-shoulder` 等写法；不强制「运动类型＋幅度＋速度」三要素模板。只要求读得出：这一镜怎么拍、景别、机位在哪、固定还是运动。

**R20.2 说话人编号与台词格式（R56 口径）。** 说话人按本段台词行顺序分配 `(S1)(S2)…`；**同一角色连续多句也逐句各占一号**（照 `分镜视频模板.md`）；不发声角色不给 ID；复合在场 `(S1,S2)`。**台词行固定 `(Sx) 角色：[Chinese] 原文`；不用 `<d>`、不写 `says`；同一角色连续多句逐句换行，不合并。** 台词原词、标点逐字保留不翻译；听不清写 `[unclear]`；标点标准化为 `, . ? !`，去 emoji 与装饰标点。**独白／画外：`(Sx) 角色（VO 不张嘴）：[Chinese] 原文`**，不另造 `S1-VO`。

**R20.3 正文引用图片一律写“图片中文名”，不写裸标签。**（2026-11-18 增补）
1. 定义行给名：`<Subject N>（图片名：<中文名>）`；`<Picture N>` 也写 `（图片名：<中文名>）`。名字取自资产表，不许用「图1」「素材A」。
2. 正文只写名字：`summary`／`detailed_description` 里引用人、场景、道具、首帧、尾帧、构图锚点，一律写图片中文名；不再出现裸 `<Subject N>`／`<Picture N>`；`retention_analysis` 行首按 R54 写 `<Subject N>（图片名：…）`。标签只留在定义行、`retention_analysis` 与「标签映射」。
3. 同名唯一：同一段同一主体只用一个名字，跨镜不换称呼；两个人同名时用资产编号区分，例 `方源（C01）`、`方源（C02）`。
4. 说话人挂名字：台词行写 `(S1) 方源：[Chinese] …`；画外音 `(S1) 方源（VO 不张嘴）：[Chinese] …`。
5. 主体名与图片名分开：人物主体名 `方源`，人物图片名 `方源全身图`／`方源面部图`；场景主体名 `荒山巅石台`，场景图片名 `荒山巅石台全景图`。正文叙事用主体名，只有明确挂某张帧／构图图时才写图片名。

**段数不预设。**段数由镜数决定，一镜一段（R63），不并段；要固定段数（如 11 段或 21 段）时另行声明，再按声明反推每集镜数，仍保持一镜一段。

## 八、声音（单镜与分段都要写）

**R21 先基础声，再本镜调制。**
有说话的镜头，声音栏先写该角色基础声（R7 五档），再写这一镜怎么加减：音量、语速、尾音、气声、停顿、句尾处理。不写「他很生气地说」。

**R22 内心独白不许张嘴（硬约束）。**
上下唇闭合、看不出开合，气声从鼻腔与齿缝出，喉部与下颌只做极小起伏。提示词里写死这条；表情栏不得出现「嘴唇开始动」「说完合上」「嘴唇开合」这类冲突描写。观众看到的是他在憋着。

**R23 台词与独白只说一遍（硬约束）。**
念完就过，不复述、不回环、不叠句。同一句原文在**可粘贴的那份提示词**（`detailed_description`）里只出现一次；元数据「说话人」栏只写说话顺序与 `(Sx)` 编号，不重复原文。官方六段前不许加中文约束行；原先那条「约束，台词与内心独白各只念一遍……」按 R56 模板收成一句英文写进 `detailed_description`：`Only the character who is speaking moves their lips; the rest keep lips closed.`

**R25 不许主动配乐（硬约束）。**
任何情况下都不许自行生成背景音乐：纯音乐、BGM、氛围垫乐、环境哼唱、片头片尾曲，一律不许，也别用「加点气氛」当理由。只有**用户在当次请求里明确要求配乐**时才写，且必须在元数据行标注「配乐（用户指定）」，写清使用区间、进入退出、动态与禁用项；没有这句标注，一律按无配乐处理。官方六段式里配乐独立成段：无配乐时 `non_diegetic_music` 写 `N/A`；用户点名才写配器/速度/节奏/动态，禁抽象情绪词。

**R34 多人同场先排说话顺序，一个人说时别人嘴不动（硬约束）。**（2026-11-16 增补）
一场里有两个以上人物在场且出现对话，先排顺序再写台词：

1. **排顺序**。剧本该场的「场景站位」下面加一行 `**说话顺序**：① 小赵 → ② 周野 → ③ 老陈`；分镜同场照抄这一行。一句一人，按这个顺序开口，不许插话、抢话、叠话。
2. **按顺序写**。分镜「台词」栏、分段元数据「说话人」只写 `① (S1) 名字 → ② (S2) 名字`，顺序必须与台词发生顺序一致；**同一时刻只许一个人说话**，说话顺序只写 ①②③，不写时间码。
3. **口型**。提示词里一句台词占一行；除正在说台词的那一个人，其余在场人物嘴唇全程闭合、不做口型、不咀嚼、不出声换气。这句必须写进 `detailed_description` 英文句：`Only the character who is speaking moves their lips; the rest keep lips closed.`
4. **无声反应**。不说话的人只做眼、眉、下颌和身体的反应（视线转向说话人、眉梢抬、喉结滚、重心换脚），不许用嘴部动作抢注意力。
5. **独白也进台词块**。`(Sx) 角色（VO 不张嘴）：[Chinese] 原文` 照样本写，占一个台词行号；`detailed_description` 的闭唇句保证画面上不张嘴，不另造 `S1-VO` 这种新编号。

## 九、生成接缝（跨段必须接得上）

**R24 上一段生成的视频，必须接得住下一段生成的视频。**
每条生成段是单独跑一次的，接缝不是剪出来再补的，是在**写的时候就对齐**的。八条执行细则：

1. **段尾收在能停的静止点。**动作完成、手停下、身体停住、重心落定；不许切在抬手一半、转身一半、话说到一半。段尾最后 3–5 帧保持终点状态，不继续发展。
2. **下一段起幅句必须写承接句。**写清谁在哪、姿势、手持物、朝向、光位与上一段末帧一致；状态若有变化，写清开头这一点怎么变的，不许凭空跳到新姿势。例，上一段收在「手机垂到腰侧、眼皮抬起」，下一段起幅就从「眼球先往左上移去看钟」起，而不是从「他站在通道里」重新起范。
3. **段首第一拍不做大动作。**先接住再走，第一个大动作放在开头稳定之后，给生成模型一个稳定的起点。
4. **跨段锁死可见状态。**道具的剩余量（烟烧到哪、桶里水多少、纸上划了几行）、服装（衣领翻没翻、袖口卷到哪）、脏污与汗、光位与时码（钟点、天光）都要接上一段。
5. **方向与轴线跨段不翻。**同一场里不越 180 度轴，出入画方向一致（上一段往画左走，下一段还往画左），视线配对保持，画左画右的站位不变。
6. **跨场次允许硬切。**但前一段必须收在一个能被打断的静止点，新段起幅句写明地点与朝向，不沿用上一场的轴线。
7. **首帧锚定用图。**H3 走首帧模式时，把上一段末帧导出当下一段首帧参考，槽位写成 `@图片 N 段尾承接帧`，紧跟在起幅句后面；两段之间动作跨度大时，这一段还必须同时给动作终点。
8. **验收法。**把第 N 段最后一行与第 N+1 段第一行并排读，能连成一句完整动作（谁在做什么，接着做），即通过；连不上就改其中一句，不改剧情、不改台词。

**R57 转场必须写明：镜与镜、段与段之间，怎么写过去、转到哪，进出要成对。**（2026-11-25 增补，硬约束）

1. **分镜层两行固定标记，不加栏。**每镜「提示词」栏里，起幅之前写一行 `承接：`，正文末尾写一行 `转场出：`；六列顺序与数量不动，这两行属「提示词」栏内容。
   - `承接：`——本集首镜写 `承接：本集开篇，<首帧可见状态>`；同场接下镜写上一镜末帧的姿势、重心、手持物、朝向、光位；跨场写 `承接：hard cut 至 <场名>，不沿用上一场轴线`。
   - `转场出：<方式>｜末帧：<定格状态>｜接：<下一镜起幅要接的五项>`，方式只从第 4 条的清单里选一个。
2. **分镜视频层两句固定。**`detailed_description` 里，镜头块之前写 `Entry:`，最后一个镜头之后、台词块之前写 `Exit:`。
   - `Entry: continuing from the previous segment, <上一段末帧状态>; the first beat only holds, no new action.`（第 1 段写 `Entry: opening segment; <首帧状态>; the first beat only holds.`）
   - `Exit: the segment ends on <定格状态>, held for the last three to five frames; hand-off to the next segment by <方式>.`（本集最后一段写 `Exit: episode ends on <定格状态>, held to the last frame.`）
3. **段边界成对。**第 N 段的 `Exit` 与第 N+1 段的 `Entry` 必须写同一个方式、同一个末帧状态；不许一处写遮挡、一处写硬切，也不许只在前段写、后段不接。
4. **方式清单，六选一。**
   - 同向运镜：推接推、拉接拉、摇接摇、跟接跟，方向与速度一致；
   - 动作匹配：上一镜动作的后半段接下一镜的前半段，方向、幅度、速度一致；
   - 遮挡转场：前景的人体、门框、衣袖、草叶、雾团扫过画面，盖住再揭开；
   - 出入画跟随：人物走出画，下一镜从同一侧进入画，速度不变；
   - 光影过渡：灯灭到烛亮、云影扫过、晨光推进，只在原文写了光的地方用（R40）；
   - 跨场硬切：只用于换场，段尾必须停住，下段起幅重写地点、朝向与光位。
   **禁用**：黑场、闪白、叠化、淡入淡出、速度突变、越轴、人物朝向翻转；淡变与叠化只有用户当次点名才写。
5. **丝滑三条硬指标，写完照这三条读一遍。**
   - 五项对得上：动作、朝向、重心、手持物、光位，末帧与次帧一致；有变化就把变化过程写进承接句，不许跳变。
   - 速度连续：上一镜收尾速度与下一镜起始速度同档，静止之后不许突然高速。
   - 声音不断：同一场的环境底声跨镜跨段是同一条，前后两段的 `overall_soundscape` 写同一种底声，不许一段有风一段死寂。
6. **密度限制。**同一种转场连用不超过 3 次；硬切只用于换场，同场切点一律用同向运镜、动作匹配或遮挡带过去；遮挡转场一集不超过 3 次。
7. **只加不改。**R24 八条（段尾静止、下段承接、跨段锁状态、不翻轴）照旧执行，R57 只规定「怎么把转场写进提示词」；不写时间码、不加第十栏、不改六段、不碰配乐与视线；转场不许遮脸、遮嘴，不许打断正在说的那句台词。

**R58 视频反推：用户给一段视频并明确说「反推」，只交分镜视频与分镜两份，逐镜复刻原片，空缺图槽写占位种类。**（2026-11-25 增补，硬约束）

1. **触发。**用户给出视频（文件、链接或截图序列），并在同一轮指令里出现「反推／逆向推／照这条片子出提示词」等明确意图，即进入反推模式。只说「看看这个视频」「分析一下」不算，先按普通问答处理，问清要不要反推。
2. **只交两份。**反推产出只有 `分镜.md` 与 `分镜视频.md`。不写 `剧本.md`、不写 `资产提示词.md`、不写人物资产三份（`人物资产-设定卡.md`／`人物资产-面部与服装.md`／`人物资产-立绘.md`）／`场景资产.md`／`道具资产.md`、不写 `项目交接.md`、不问题材、不问画风、不问「先生剧本还是跳过剧本」、不问场景与道具 A／B／AB。用户没额外点名要别的，就不许顺手多给。
3. **逐镜复刻，一个字都不许改剧本内容。**镜数、镜序、每镜时长、景别、机位高度、运镜方向与速度、构图（人在画左／画右／居中、头顶留空多少）、人物数量与站位朝向、动作起止与承重点、表情与视线落点、光位与色温、台词句数与口型段、环境声与动作声，全部照原片；不合并镜、不拆镜、不补原片没有的镜、不删原片有的镜、不调场次顺序、不改台词。原片多少镜就多少镜，原片一镜 2 秒就写 2 秒。
4. **无差别四条硬指标，交付前逐条核。**
   - 镜数与每镜时长对得上原片（按抽帧时间轴数镜、量秒）；
   - 每镜景别、机位、运镜方向与构图对得上；
   - 人物动作的起止状态、朝向、重心、手持物、光位对得上；
   - 台词句数与口型段、环境声与动作声对得上。
   四条有一条对不上就回头补，不许标称「已还原」。
5. **空缺图槽写占位种类。**反推时用户手里没有实拍资产图，所有图槽一律写占位名，**不编 `@C01／@S01／@P01` 真编号，不写「已出图」「见附图」**。
   - 命名：人物类 `人物一`／`人物二`／`人物三`…，场景类 `场景一`／`场景二`…，道具类 `道具一`／`道具二`…；中文数字，从「一」起。
   - 排号：只有一个人物就写 `人物一`；原片出现多个人物，按出场顺序写成 `人物一`、`人物二`，场景与道具同理。**同一人物／场景／道具全片固定同一个号，只顺排、不重排、不回收。**
   - 落位：分镜「参考图」栏写 `@图片 1 人物一（空缺占位）`；分段 `subject_definitions` 写 `<Subject 1>（图片名：人物一）`，`retention_analysis` 行首也写 `（图片名：人物一）`。
6. **占位不等于省描写。**没有图，靠字面把「像」写出来：每个角色写足性别、年龄段、发型发色、脸型五官特征、身高体态、服装款式颜色材质与磨损、鞋帽配饰、标志细节（疤／痣／胡须／眼镜／兵器）；场景写空间布局、锚点物、材质、色温与雾尘；道具写形状、尺寸参照、颜色与磨损。同一角色跨镜跨段用**同一句固定特征句**复述，一致性靠这句话锁；不许越写越变样、不许凭空加特征。
7. **只反推看到的。**不脑补剧情与前因后果、不加原片没有的动作、不换人物身份、不改台词；原片听不清的台词写 `(Sx) 角色：[Chinese] （听不清）`，保留该句口型段长度，不编词；原片有明显穿帮、遮挡、黑场、叠化，按原样写进 R57 的 `承接／转场出` 与 `Entry／Exit`——**这是 R57 禁黑场／禁叠化的唯一例外：原片用了就照写，并在交付里写一句「原片用了 X，已照写」。**
8. **结构照旧。**六列、Ref2VA 六段、分镜不写时间码、分段首镜无时间码后续镜 `At MM:SS.mmm`、台词 `(Sx) 角色：[Chinese] 原文`、人物不看镜头、`non_diegetic_music: N/A`、只照原片写光、`@图片 N` 槽号——全部照旧；R57 转场照写，段段成对。
9. **反推不做的五件事。**不押题材、不算对白字数与开口占比、不套 220–260 秒的一集口径（原片多长就多长）、不建集不打资产表、不跑全量自检与项目交接；只跑 `check_rule.py --reverse` 的两份结构校验。

**R59 有特效的场面，三层照 `references/特效模板.md` 写。**（2026-11-25 增补，硬约束；模板由三份成品文档固化：一条 28.77 秒、5 场 15 镜的玄幻特效片剧本／分镜／分段）

1. **触发。**小说或剧本里出现下列任一类，本场三层按特效模板写：法阵与阵法（地面光环、头顶同心环、六芒星、符文圈、结界、封印）、能量体（能量手、光柱、光索、剑气刀芒、护体光、法相）、元素异象（火、雷、冰、风旋、雾涡、血雾、毒瘴）、器物活化（符文锁链、飞剑、塔钟镜、傀儡、法器自转）、变身与状态（能量体转实体、瞳色变、皮肤浮符纹）、天象与空间（云海涡心、巨柱升起、天地倒置、空间裂隙、幻境切换）。纯现实打斗、没有任何光效与超自然元素的场不套，不许硬造特效凑模板。
2. **剧本层密度。**一场 1–4 个特效，**一行一个** `[VFX] 名称｜形态：…｜光源：…｜起：…｜中：…｜收：…`，不并写、不嵌套；名称写本体叫法与归属（`道具一 符文锁链`、`头顶同心法阵`）。
3. **形态写五件事。**① 本体材质与颜色；② 内部结构（符文、星线、电弧、裂纹）；③ 边缘处理（泛光、毛边、速度模糊、吞光）；④ 体积与透明度（半透明紫、漆黑哑光、白色半透）；⑤ 与参照物的比例。只写「炫酷红光」「特效拉满」「光效强烈」不合格（R39 第 5 条照旧）。
4. **光源与光。**`[VFX]` 的光源段写「谁照亮谁、投影朝哪、冷暖与色温」；另起一行 `[LIGHT] 光源｜方向｜强度／色温｜落点／变化`。特效自带光源时必须写，因为它就是这一场的主光；原文没写光、特效也不发光的场不加光（R40）。
5. **起、中、收与形变。**起写「从哪出现、谁触发、几拍到位、起始形态」；中写「持续多久、怎么变、带什么风热受力」；收写「怎么衰减或定型、停在哪个可截帧的状态、留下什么」。本体发生质变（能量→实体、光→烟、透明→实心）必须写清三段式：**第几拍开始变 → 变成什么（材质／颜色／表面处理）→ 变完停在哪**。
6. **人特效互锁。**特效不悬空，一定作用在人、物、云海上，用握、缠、托、穿、裹、压、扣、刺、贯、绕这类关系动词写清；正文按「特效起 → 人物反应 → 特效推进 → 人物再动」交替写，一行一件事，不把两件事挤进一句；人物受特效光照时写清哪一侧受光、暗部压到哪；特效不许遮脸、遮嘴、压住台词口型。
7. **`[SFX]` 一特效一行、声音三层。**低频底（法阵低频轰鸣、能量凝聚嗡鸣）＋瞬时声（电弧噼啪、符文逐一亮起的串联脆响、链环收紧闷响）＋空间余响（长风、余鸣、衣料发丝）。全写画内声，不写 BGM、不写「配乐渐强」（R25）。
8. **分镜层。**场标题括号里列出本场特效清单；同一特效落进四处——「动作」（`特效：` 起头写当前形态与作用对象）、「动作先后」（① 起 ② 中／峰值 ③ 收）、「自然规律」（照亮谁、投影朝哪、风热怎么推动云与衣料、符文亮起顺序）、「提示词」（起→中→收三个可见阶段逐句写，一句一阶段，每句带材质颜色光向，阶段之间用随后／继而／逐渐衔接，末句停在稳定可截的末帧）。六列数量与顺序不动，不另立「特效」栏。天象类先给全景坐标（占上幅／下幅、中央或哪侧、水平或垂直），再给局部特写，一镜不混两个尺度。

**R60 段与段之间必须接得上：要么接到看不出来，要么在前段末尾／后段开头写明一个看得见的转场。**（2026-11-25 增补，硬约束；写法模板见 `references/分镜视频模板.md` 顶部补注）

1. **二选一，不许留白。**第 N 段与第 N+1 段之间只走两条路：**A 无缝接**或**B 显式转场**，并在 `Entry:`／`Exit:` 里写明是哪一种。两条都不写，或只写 `cuts to`／`hard cut` 而写不出看得见的那一拍，等于没接上。
2. **A 无缝接（同场首选）。**成立条件：同一场、同一机位方向、末帧与次帧是**同一动作的连续相位**——推接推、拉接拉、摇接摇、跟接跟、动作匹配（上一个末镜的手／兵器／衣摆继续到下一段首镜）、出入画同侧；中间不加任何转场画面，两段剪在一起看不出接缝。前段 `Exit` 末尾写 `hand-off seamless — no transition frame, <下一段接手的那一个连续动作>；`；后段 `Entry` 写 `continuing from the previous segment in the same camera setup — <末帧状态原样接住>；hand-off seamless, no transition frame;`。
3. **B 显式转场（换场、时间跳跃、必须换轴线、两段状态接不上时用）。**在前段 `Exit:` 之后、台词块之前单独加一行 `Transition out: <方式> — <一句看得见的转场动作>；`；在后段 `Entry:` 之后加一行 `Transition in: <同一方式> — <从什么画面进来>；`。两行方式必须同名（照抄），转场句必须写成可见的一拍：甩镜甩成虚影、前景物（衣袖、手臂、雾团、链环、门框）扫过盖满画面、同向运镜推到虚焦、光效（法阵光、电弧、火光、云影）吞满画面、人物走出画再从新场同侧走入。只写「镜头切换」「hard cut 到场景 X」不算写了转场。
4. **位置固定。**转场只能写在前段最后一个镜头之后（`Exit:` 上下）或后段第一个镜头之前（`Entry:` 上下）；不许写进段中间、不许写进台词块、不许另立新字段、不许改六段结构。
5. **方式与 R57 同一套。**B 只用六种：同向运镜、动作匹配、遮挡转场、出入画跟随、光影过渡、跨场硬切；硬切只用于换场；禁黑场、闪白、叠化、淡入淡出（用户当次点名或反推原片照写除外，R58）。
6. **剪辑点规矩。**接缝不许切在说话中途、表情变化中途、半个动作上；A 落在同一动作正在进行的同一拍，B 落在动作能停住的拍子上（末帧静止 3–5 帧再转）。段长 4–10 秒、镜长 1–10 秒、一集 220–260 秒不变。
7. **密度。**同场优先 A；一集 B 不超过段间数量的一半（换场多可放宽）；同一种 B 方式连用不超过 3 次（接 R57）。
8. **自检。**逐对检查两段是否都写了 `seamless`，或都写了 `Transition out:` 与 `Transition in:` 且方式同名；只一处写、方式对不上、B 只有 hard cut 没有转场句即 FAIL；整份旧稿一处标记都没有只提醒，不回溯。

**R61 打斗场面三层照 `references/打斗模板.md` 写；带光效时与 R59 叠用。**（2026-11-26 增补，硬约束；模板由用户提供的三份成品文档固化——一条 15.1 秒、1 场 12 镜、3 段、全片无对白的兵器对打片）

1. **触发。**兵器对打、徒手格斗、群战围攻、追击截击、受击与击飞、一击定胜负、起势对峙任一类，本场三层按打斗模板写。只有口角不动手、只有招式名没有身体动作的场不套。**打斗里带刀气／剑气／刃光／光团／核心／法阵／异象等光效时，本模板与 R59 特效模板同时套**：`打斗回合`（或 `[FIGHT]`）与 `[VFX]` 两套标记并存，特效作用在接触点上，不合并不互代。
2. **剧本层先写「打斗回合」。**每场在 `[LIGHT]`／`[VFX]`／`[SFX]` 之前写 `**打斗回合**（本场 N 回合）`，一回合一行 `- 回合 N：谁先动｜接触点：…｜结果：…`；三段缺一段不合格（「两人打了起来」「不分胜负」不算写）。一场 1–3 组打斗、一组 3–6 回合。
3. **剧本正文一回合一段四句式。**起势句（谁先动、蹬地、重心压哪条腿、上身朝哪）→ 接触句（兵器／身体在哪一高度哪一角度接上、谁压谁）→ 受力结果句（谁被推成什么姿态、碎什么飞什么、光往哪爆）→ 姿态句（回合结束时两人各停在哪、手持物与呼吸）。身体写到膝、髋、肩、前臂、腕、咬肌、颈侧。
4. **攻守交替与局面变化。**不许连续三回合同一人进攻；被压一方每回合至少一个有效反制（架、磕、侧移、退步卸力）；每回合至少一方姿态变化；**每场至少一次局面变化**（压上被反压、退走、被击飞、被钉住）。不许凭空给能力：崩石板、腾空旋斩要有剧本前置（武器／功法／体型），否则分镜不许加。
5. **声音与无对白。**`[SFX]` 一回合一行（或一特效一行）写三层：低频底（高空风／甲胄咯吱／踏地闷响）、瞬时声（金属锵鸣／闷响重击／碎甲叮当／低频轰鸣）、空间余响（碎石落地噼啪／空场回声／非人低鸣）。全片无对白时剧本头写 `说话顺序：全片无对白`、分镜「台词」写 `无`、分段 `* 说话人：无`；真有话只能落在回合间隙（被击退、错身、落地）说一句，刀锋相抵时开口不合格。默认零配乐（R25）。
6. **分镜层一镜一回合，镜序固定。**打斗镜 **4–6 秒**（R63 下限 4 秒；原来 1–2 秒的快切镜在分镜层并进相邻镜）；一回合可并成一镜、也可拆两镜（前一镜收在接触瞬间、后一镜从受力结果起），一个 4–6 秒镜最多装 1–2 个回合；镜序 **起势镜 → 接触镜 → 受力镜**，不许颠倒；一场 ≥4 镜（起势 1 ＋ 交手 ≥2 ＋ 收势 1），靠打斗推进可到 6–8 镜。「动作先后」≥3 拍（蹬地／送肩 → 挥出 → 咬合 → 爆开 → 后仰／退步），每拍一个动作；「自然规律」写足受力结果（裂纹走向、碎石弹起方向、尘浪翻卷、瞬时强光照亮谁与投影朝哪）；「表情」先一句情绪定调（几成、冲谁）再写发力肌肉与视线落点。
7. **每击必落可见结果。**不许「两人激烈交锋」「一顿猛攻」「打得难分难解」一句带过（接 R43／R51）；每一击至少一个结果：后仰、下沉、退步、裂石、碎甲、弹开、火星、击飞。
8. **打斗镜六条硬规矩。**① 不许在一个动作中途切镜，切点落在接触后、受力完成的静止拍；② 同场不越 180 度轴，画左画右与出入画方向不变；③ 视线追对手刀路／胸口／下盘，不看镜头（R49／R52）；④ 同一瞬间两人各写各的，一人一动作；⑤ 每击必有结果；⑥ 打斗镜不塞内心戏，回忆与独白另开镜。
9. **分镜视频层一段一镜、镜内 1–2 回合（R63）。**打斗段同样一段只有一个 `[Shot 1]`，段长＝该打斗镜的 4–6 秒（原来 5 秒装 3–5 个 `[Shot]` 的写法作废）；断段点选在接触完成、姿态停住的拍子上，不许断在挥砍半途；`[Shot 1]` 写「起势动词 → 兵刃在哪咬合 → 谁被推成什么姿态」（第二回合用 `then` 接在主句后），每句至少一个受力结果英文词（`blades lock`／`cross-parry`／`shockwave`／`dust wave`／`stone cracks`／`debris flying`／`stagger`／`bracing back`／`thrown back`），并写机位与速度（`handheld violently shaking on impact`／`camera panning with the spin`／`low-angle looking up with the leap`）；术语全片一致（`upward cut`／`downward chop`／`ground-skimming arc`／`airborne spin slash`…见模板 3.3 表）；`overall_soundscape` 一句串完风底 → 金属 → 碎甲／碎石 → 非人低鸣 → 余响，落 `no intelligible dialogue`。
10. **镜间与段间。**打斗镜照 R57 写 `承接：`／`转场出：`：同场连续交手优先动作匹配与同向运镜，击飞与横移用出入画跟随，尘浪／衣袖／兵器横扫用遮挡转场，有光效时用光影过渡做桥；相邻段照 R60 二选一——同一场连续打斗优先 A 无缝接（末帧停在接触或姿态，下一段从同一动作的下一拍起），换场地／时间跳跃／击飞落到别处走 B 显式转场（`Transition out:`／`Transition in:` 同名）。禁黑场闪白叠化，不许遮脸遮嘴、不许拦腰打断。
11. **只加不改。**六列、Ref2VA 六段、分镜不写时间码、台词只说一遍、默认零配乐、人物不看镜头、资产只出提示词、R57／R58／R59／R60 全部照旧；打斗不新加栏目——「打斗回合」写在剧本正文之前，回合只落进既有六列与六段；反推打斗片按本模板复刻回合与受力结果，图槽仍写 `人物一／场景一／道具一` 占位。

## 十六、工程注意事项（踩过的坑）

1. **台词行格式**，必须顶格写 `角色：台词`，说话人不超过 8 字、不含标点与括号；否则解析正则 `^([^\s：:\[\]#]{1,8})[：:]\s*(\S.*)$` 会静默漏检。语气另起一行写。
2. **动作里不用冒号**，用逗号，否则会被当成新的角色台词行。
3. **批量改文件要保住结构**，按「提示词」栏切分再回写会吞掉它后面的场标题与站位段，改完必须核对 `### 镜头` 与 `## 第 N 场` 的数量。
4. **标题行不要粘连**，回写后检查有没有 `…下巴。### 镜头 1-10 ｜` 这种把标题挤到上一行末尾的情况。
5. **编号断链**，`C`、`S`、`P` 若每集重排或回收旧号，上一集的 `@C01` 会指到另一个人；只顺延，不重排。
5. **大文件分块写**，单次写入控制在两万字以内。
