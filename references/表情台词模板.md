## 零 启用判定

### 0.1 什么时候套

一场里出现下面任一类，就**整场**按本模板写三层：

| 类别 | 触发长相 |
|---|---|
| 两人对话 | 一来一往 ≥3 句，有明确回应关系（问—答、指认—辩解、劝—拒） |
| 多人对质 | 三人以上同场，有「谁先说、谁接、谁插、谁只听」的次序 |
| 独白／回忆 | 内心独白（VO）、回忆旁白、酗酒自语，人物不对外说话 |
| 控诉与哭诉 | 指认、翻旧账、委屈、落泪，情绪有起伏过程 |
| 劝说说服 | 拉拢、谈条件、许好处，语气有软硬切换 |
| 审问与逼问 | 追问、逼答、拒不开口，一问一逼 |
| 表白与告别 | 情绪高点靠台词承载，说完要留反应镜 |
| 群体议论 | 群像七嘴八舌、交头接耳、附和与反驳 |

### 0.2 什么时候不套

- 只有一句过场招呼（「你好」「让让」）且不承载情绪 → 按普通台词处理，不建「说话顺序」大表。
- 纯动作场面无对白 → 走 R61 打斗模板（无对白写法）。
- 只有旁白说明、没有一个可见人物在演 → 归 `[SFX]`／叙述，不进表情栏。

### 0.3 规模

- 一场 2–6 个说话人（群众算 1 个「群像」说话人）。
- 一场至少 2 次话轮交换（一人说完另一个人接），否则只是「发言」不是「对话」。
- 一集台词总字数按 `references/题材规范.md` 的对白字数区间（默认 200–600 字）；本模板只管怎么把台词写进三层，不额外加减字数。
- 每段（4–10 秒）装 1–4 句台词为宜；超过 4 句要拆段，别把 10 句塞进一段。

## 一 剧本层写法

### 1.1 场头两行不能少

```
**场景站位**（锚点：场景二 竹柱与深色帷幔）：…
**说话顺序**：① 人物三 → ② 人物五 → ③ 人物三
```

- `说话顺序` 用带圈数字串箭头，**全片按出现先后连续编号**（① 到 ㉔ 都行），一人说两次就出现两次。
- 内心独白在后面标 `（VO 不张嘴）`；群里同时出声的写一个人名（如「人物五」代表群像）。
- 说话顺序要与正文台词行的顺序**逐条对齐**：第 3 个 ①→②→③ 里的 ③，必须就是正文第 3 处开口的人。

### 1.2 台词行：一句一行，不带任何修饰

```
人物二：各位族人。
人物二：就是我面前这个人。
人物三：你不要血口喷人。
```

- 只写 `说话人：原文`。**不加** `[Chinese]`（那是分镜视频层的事）、不加 `（压低声音）` `（冷笑）` 之类括注、不写「他说」、不用引号。
- 听不清就照实标：`人物五：（听不清）`，不编词。
- 一人连说多句 → 每句单独一行，不合并成一句带逗号的长句。
- 两人不许写在同一行同时出声；真要抢话，写成两句中间夹一句「两个声音叠在一起」，仍各占一行。

### 1.3 开口之前先写身体（台词之间的叙述句）

台词块不是背靠背堆着的，**每 1–4 句之间要插一段可见的身体与表情准备**，格式是「谁 + 做什么 + 表情落到哪」：

```
人物三先垂眸，单侧嘴角缓慢牵起，随后抬眼开口，下颌微抬，碎发随头部轻晃。
人物二攥着虫的手抬在胸前，胸口随说话起伏，下颌前送，眉头越皱越紧，脖颈筋线鼓起。
```

四条写法：

1. **先准备后开口**：抬眼、抬头、吸气、松肩、攥拳，再出声；不许话已经说完才补表情。
2. **一人一次**：同一段叙述句里只写一个人的身体，别把两个人揉在一句。
3. **表情写到关节**：眉（压／挑）、眼（眼睑／瞳孔／眼尾）、鼻（鼻翼翕张）、嘴（唇角／咬肌／牙关）、颈（喉结／筋线）、肩颈、手（指节／掌心／攥松）、上身（前倾／后仰／侧让）、重心。
4. **听的人也有戏**：听者不给台词，但给反应——侧身、垂眸、退半步、肩颈绷住、眼皮缓慢抬起。

### 1.4 情绪两层：定调 + 清单

表情句必须两层齐全：

- **定调**：`情绪 + 几成 + 对着谁`。例：`不屑讥讽，五成傲气，眼皮半垂扫向画外人物二`。
- **清单**：定调之后紧跟可执行的肌肉与关节动作（见 1.3 第 3 条）。

只有形容词（「他很生气」「气氛紧张」）＝不合格；只有肌肉没有定调＝不合格。

### 1.5 全片两份总表（剧本结尾必须写）

```
## 声音设定
- 人物一：男中低音，声线平直偏冷，语速稳，句尾下压，音量克制；内心独白时气声一半、音量再降两成、语速更慢。
- 人物二：男中音偏粗，情绪上来音量拔高，喉音重，受礼推辞时语速快、音调放低。

## 表演总则
- 情绪先定调：一句写清什么情绪、几成、对着谁；下一条再写这份情绪对应的肌肉与关节动作，两层缺一不可。
- 内心独白全程不张嘴，上下唇闭合，气声走鼻腔与齿缝，喉部与下颌只做极小起伏。
- 同场多人对话一句一人，只有说话的人做口型，其余在场人物嘴唇全程闭合，只给眼、眉、下颌与身体反应。
- 全片不配乐，只保留环境底声与动作声。
```

- `声音设定` 一人一行：音色（男女／中低音）＋语速＋音量＋句尾走向＋特殊情况（喝醉、压怒、内心独白）。这份表是给配音与「尾音」写法用的底稿。
- `表演总则` 固定四条，一句话不改；它是 R34／R49／R25 在本模板里的落地口径。

### 1.6 声音标记

- 对白场 `[SFX]` 写三层：**底声**（人群、风声、烛火噼啪）／**台词层**（嗓音质感：「粗粝嗓门压着怒意」「清亮尾音上挑」）／**余响**（话尾散进背景的距离感）。
- 只写画内声，不写配乐（R25）。

## 二 分镜层写法

### 2.1 「台词」栏：只写说话次序，不抄原文

```
- 台词：① 人物二 → ② 人物二 → ③ 人物三
- 台词：① 人物一（VO 不张嘴）
- 台词：无
```

- ① 是说话顺序，与剧本 `说话顺序` 的编号对齐；**本镜谁开口就写谁**，同一人连说两句就写成 `① 人物二 → ② 人物二`。
- 台词原文一个字都不进分镜（进分段的台词块）。
- 内心独白标 `（VO 不张嘴）`；本镜无人说话写 `无`。
- 群众说话写群体名（如「人物五」）。

### 2.2 「表情」栏：定调 + 五段清单

按下面顺序写，一句话能读完，但五样不能缺：

| 段 | 写什么 | 例 |
|---|---|---|
| 定调 | 情绪＋几成＋对着谁 | 愤怒到涨红，两颊泛红，视线钉在画外人物三方向 |
| 上半脸 | 眉／眼睑／瞳孔 | 粗眉压下、双目圆睁、瞳孔平直不眨 |
| 中部 | 鼻翼／咬肌／牙关 | 鼻翼翕张、咬肌反复鼓起、牙关紧咬 |
| 下半脸与颈 | 唇角／下颌／喉结／筋线 | 唇角压平、下颌前送、喉结滚动、脖颈筋线鼓起 |
| 身体 | 肩颈／手／上身／重心 | 肩颈绷住、攥着虫的手抬在胸前、上身前倾半寸 |

三条补充：

- **不看镜头**：表情栏末句固定写「不看镜头」或「目光落在画外人物X方向」（R49／R52）。
- **手部／道具特写镜**：确实看不到脸时写「本镜只露手部…人物面部在画外」，然后照常写手部细节（指节泛白、皮肤粗粝）。
- **反应镜**：只写眼、眉、下颌、肩颈，写「视线越过人群落向场中」，不许点头如捣蒜、不许抢说话人的戏。

### 2.3 「声音」栏：写嗓音，不写台词

```
- 声音：人物二粗粝嗓门压着怒意，群众议论在四周压低。
- 声音：人物三讥诮尾音拖长，群众骂声在背景由稀到密。
- 声音：背景人声退到最低，人物一内心独白（VO），本人不张嘴。
```

四样至少给三样：**嗓音质感**（粗粝／清亮／含混）＋**语速或音量**（拔高、压低、加快、拖长）＋**背景层**（群众议论、烛火、脚步）＋（独白时）**本人不张嘴**。

### 2.4 提示词：表情句嵌在动作句之后

顺序固定：`承接：` → `起幅：`（含固定特征句）→ 动作句 → **表情句** → （可选）`切：` → `转场出：`。

表情句写法（照成品）：

```
人物二攥着虫的手抬到胸前，胸口随说话起伏，下颌前送，脖颈筋线鼓起；两颊涨红、双目圆睁、眉头紧锁、鼻翼翕张，视线钉在画外人物三方向，咬肌反复鼓起，呼吸粗重。
```

- 动作在前、表情在后，用分号接；表情句里带上**一次呼吸或一次喉结**，人物才活。
- 说话的人写开口动作（下颌前送／嘴唇开合／牙关），听的人写「嘴唇闭合，只给眼眉反应」。
- 群像反应镜写「眉尖蹙起、嘴角下撇、目光投向画外X方向」。

### 2.5 分镜镜序与镜长

- **正反打**：说话镜 **4–6 秒**，紧接听者反应镜 **4–5 秒**（R63 一镜一段、镜长下限 4 秒；原来 3 秒的反应镜并进相邻镜）；不连续对切超过 3 次（第 4 次必须换机位高度或加一个插入镜）。
- **过肩**：双人对话用过肩中景／近景，保持视线配对（画左看画右、画右看画左），不越轴。
- **插入镜**：手部、道具、群众反应，用来打断长对白；**4 秒起**，不足 4 秒的并进相邻的说话镜或反应镜（R63：一镜一段、不许两镜塞一段）。
- 对话镜的**转场**照 R57：正反打一律写 `转场出：硬切（正反打）`；离开对话场时走动作匹配／遮挡／光影过渡。

### 2.6 六条硬规矩

1. 表情栏不写「他很生气」「气氛凝重」这类结论句。
2. 台词原文不进分镜。
3. 一镜一表情定调，不在一镜里演两种情绪（除非镜内明确写「先…随后…」）。
4. 说话人与听者必须同框或有反应镜，不许对着空气说话。
5. 人物绝不对视镜头、不对镜头表演（R49／R52／R54）。
6. 哭与笑不许只写「哭」「笑」，必须写可见执行（泪滑过颧骨、喉头抽、鼻翼张、唇角抖）。

## 三 分镜视频层写法

### 3.1 「表演参考」行

```
* 表演参考：综 03 冷静（肩背平直、眼皮半垂）；群像议论（眉尖蹙起、交头接耳）。
* 表演参考：综 17 隐忍怒意转怒容（指节收紧、喉结滚动、双目圆睁）；道具 06 手部特写（捏虫）。
```

- 编号取自 `references/表演参考/微表情.md`：`综01–综25`（综合）、`哭/笑` 各自编号；动作取 `动作与肢体.md` 的 `动作 NN`。
- 写法：**编号 + 情绪名 + 括号里 2–3 个可执行动作**，与库内小标题同名（允许按镜微调，如「隐忍怒意转怒容」）。
- 一段 1–3 条；群像写「群像＋动作」，找不到编号就用动作描述。

### 3.2 「说话人」行

```
* 说话人：① (S1) 人物五
* 说话人：① (S1) 人物二 → ② (S2) 人物三
* 说话人：① (S1) 人物一（VO 不张嘴）
* 说话人：无
```

- `①` 是话轮号，`(S1)` 是**该话轮第一句台词的编号**；下一话轮依次写 `② (S2)`…（若第一话轮说了三句，第二话轮就从 `(S3)` 起? 不——样本口径为 `② (S2)`，S 号按说话人轮次走，逐句在台词块里连排）。
- 台词块的 `(Sx)` 在**本段内从 (S1) 连续递增**，一人多句各占一号；跨段重新从 (S1) 起。
- 独白标 `（VO 不张嘴）`，与剧本、分镜三处同名同样。
- 本段无人说话写 `无`，台词块整块不出。

### 3.3 detailed_description 头两句固定

```
The scene is 场景一. An outside witness records the back-and-forth before the tent. No subject looks into the lens, and no subject adopts the frontal gaze of the reference sheets; figures stay in profile or three-quarter view, pupils off frame at the opponent.

Only the character who is speaking moves their lips; the rest keep lips closed.
```

- 第一句：场景＋谁在观察＋所有人不看镜头、不继承正面视线（R49／R54）。
- 第二句：**一段里但凡有 ≥2 人说话就必须有这句**（R34 一人说时别人嘴不动）；独白段改写为 `the speaker keeps lips closed while the inner monologue runs`。

### 3.4 每 Shot 的英文表情三句

一句一个镜头的表情，顺序：**定调 → 眼与眉 → 下半脸与颈 → （可选）呼吸与手**。

```
His eyelids half drop, brows relaxed, pupils scanning off-frame stalls and crowd, calm and aloof with three parts scrutiny.
```

```
He lowers his eyes first, one corner of the mouth curling up slowly in a cold smirk, then lifts his eyes and chin to speak, brows lifted at the outer ends, eye corners slanting, smile not reaching the eyes, gaze landing on off-frame 人物二.
```

规则：

- 情绪必须带**几成**（`three parts scrutiny`／`four parts chill`／`with two parts contempt`）。
- 说话镜写口型：`lips opening on the first word`／`jaw moving with the line`／`chin lifting to speak`；听者镜写 `lips closed, only eyes and jaw react`／`lids lifting slowly`。
- 独白镜写 `lips pressed together, breath through the nose, throat moving only slightly`。
- 哭／笑写执行：`a tear sliding down the cheek`／`shoulders shaking once`／`a laugh that dies at the tail`。

### 3.5 台词块位置与格式

- 位置：`Exit:` 之后、`overall_soundscape:` 之前。**不许**夹在镜头之间、不许放段首。
- 格式逐字：`(S1) 人物二：[Chinese] 分明就是一只最普通的臭屁肥虫。`
- 一句一行，编号连续；不合并、不加语气标、不改写原文；VO 行前不加括号说明（VO 说明只在「说话人」行里）。
- 一台词块的行数＝本段「说话人」行覆盖的句数，多一句少一句都算错。

### 3.6 overall_soundscape 写嗓音不写台词

```
Tent-side crowd murmur dropping to a hush; rough breathing from the accuser; faint cloth creak; the retort in a clear soft voice with a drawn-out mocking ending.
```

- 要给：**底声**（人群、风、烛火）＋**嗓音**（rough／clear soft／drunken slurred／level flat）＋**情绪尾音**（drawn-out mocking ending／voice cracking at the tail）＋独白时 `while the speaker keeps lips closed`。
- 不抄台词原文、不写 BGM（`non_diegetic_music: N/A`）。

**交付前删尾注。**反推稿或别人给的成品末尾常带「> （注：部分内容由豆包 AI 生成）」这类注释行，它会落进最后一段的 `non_diegetic_music` 与最后一镜的「提示词」里，自检会把 `N/A` 判成没写。交付前把这类尾注删掉或移到文件外。

### 3.7 表情与口型英文术语（固定表，写了就照抄，别换同义词）

| 中文 | 固定英文 |
|---|---|
| 眉头压紧 | brows knit / brows pressing down |
| 眉梢上挑 | brows lifted at the outer ends |
| 眼睑半垂 | eyelids half drop |
| 眼皮缓慢抬起 | lids lifting slowly |
| 瞳孔平直不眨 | pupils level and unblinking |
| 眼尾斜压／眼角笑纹 | eye corners slanting / eye corners crinkling |
| 目光钉在画外某人 | gaze pinned off frame at + 名 |

## 四 三层对照例（同一次「冷笑反驳」）

**剧本层**

```
人物三垂眸侧头，抬手以手背掩在唇前，鼻腔里哼出一声，肩颈松垮半寸；放下手，下巴抬起，上身微仰，眼皮半垂扫向画外人物二。

人物三：呸。哼。
人物三：是你自己贪小便宜。
```

（场头 `**说话顺序**：… ⑤ 人物三 …`，台词一句一行，开口前先写掩唇哼气与松肩。）

**分镜层**

```
- 拍摄手法：近景｜平视 1.5 米｜固定机位，极轻微推近｜镜长 4 秒｜理由：冷笑与反驳是本段情绪高点，近景承载单侧嘴角的嘲讽弧度。
- 动作：人物三先垂眸，单侧嘴角缓慢牵起，随后抬眼开口，下颌微抬，碎发随头部轻晃。
- 动作先后：① 垂眸、手背掩唇；② 单侧嘴角牵起；③ 抬眼开口、下颌微抬。
- 表情：不屑轻嘲，四成，眼尾斜压、眼皮半垂，鼻翼轻张，单侧嘴角压着笑、笑不到眼底，喉结轻滚，视线扫向画外人物二方向，不看镜头。
- 声音：人物三嗓音清亮、语速偏慢，呸字短促带鼻腔哼气，尾音上挑。
- 台词：① 人物三 → ② 人物三
```

## 五 验收十条

1. 剧本有 `说话顺序` 一行，编号与正文台词逐条对齐，VO 都标了 `（VO 不张嘴）`。
2. 台词一行一句、`说话人：原文` 干净，不带 `[Chinese]`、不带括注、不写「他说」、听不清照标。
3. 每 1–4 句台词之间有一句可见的身体准备（抬眼／吸气／攥拳／松肩），不是话赶话。
4. 表情句两层齐全：情绪＋几成＋对着谁，加上眉、眼、鼻、嘴、颈、手的具体执行。
5. 剧本结尾有 `声音设定`（一人一行）与 `表演总则`（四条）。
6. 分镜「台词」栏只有次序（`① 名 → ② 名`）或 `无`，没有一个字的台词原文。
7. 分镜「表情」栏五段齐、末句不看向镜头；手部特写镜写清「面部在画外」。
8. 分段「表演参考」用 `综NN` 编号＋情绪名＋2–3 个可执行动作；「说话人」行写到 `(Sx)`。
9. 分段有「Only the character who is speaking moves their lips…」；台词块在 `Exit` 后、`overall_soundscape` 前，`(Sx)` 段内连续递增、一句一行带 `[Chinese]`。
10. `overall_soundscape` 写了嗓音质感与情绪尾音，不抄台词、不写 BGM。
