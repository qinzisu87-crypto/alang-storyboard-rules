# 打斗场景模板（R61）
> **R70 字段映射**：本条里的「拍摄手法／动作／动作先后／表情／自然规律／声音／台词／参考图／提示词」按新三件套落位——拍摄手法→列5 镜头层；动作与动作先后→列5 逐秒指令（每秒一条）；表情→列5 逐秒＋列6 表演提示；自然规律→列3 光照基线＋列5；声音→列6；台词原文→列6（列5 只写开口）；参考图→列3 绑定与 `@图片 N`；承接／转场→列2 交棒。旧稿九栏体照旧可读。


> 来源：用户提供的三份成品文档（`剧本.md` / `分镜.md` / `分镜视频.md`，一条 15.1 秒、1 场 12 镜、3 段、全片无对白的兵器对打片：石台对冲 → 贴身连斩 → 击飞腾空 → 终结定格）。
> 用途：**小说或剧本里有打斗场面时，三层照这份模板写**。本模板与 `references/特效模板.md`（R59）叠用：**打斗给骨架（谁先动、接触点、结果、姿态），特效给光（刀气、光团、核心、尘浪）**。两份一起就是「打斗特效模板」。
> 与 R59 的分工：纯现实打斗（拳脚、刀剑、追打，无光效）只套本模板；打斗里带刀气／剑气／光团／法阵／能量体／异象，就本模板＋特效模板一起套，`[FIGHT]` 与 `[VFX]` 两套标记并存，不合并、不互相代替。

## 零、什么时候启用

出现下列任一情况，本场按打斗模板写：

| 类别 | 具体表现 |
|---|---|
| 兵器对打 | 刀剑相击、长短兵对冲、双刀压单刀、枪挑刀格 |
| 徒手格斗 | 拳脚、肘膝、擒拿、摔投、锁技 |
| 群战围攻 | 一对多、多对多、阵中混战、车轮战 |
| 追击截击 | 边跑边打、途中截击、退走中被压上 |
| 受击与击飞 | 被连打退步、被打飞、落地翻滚、撞墙撞石 |
| 一击定胜负 | 蓄力、贯地、终结一击、定格对峙 |
| 起势与对峙 | 蹲伏、拔刀、绕步、拉距离、眼神压迫（打斗前奏也算） |

不套本模板：只有口角与威胁不动手、只有招式名没有身体动作、纯特效展示而无交手。

**每场打斗的规模**

- 一场 1–3 组打斗；一组 3–6 个回合（回合＝一次「谁先动 → 接触 → 结果」的完整交换）。
- 一集打斗总量按剧情给，建议 90–150 秒（一集 220–260 秒，R37 不变）；打斗不是全片时，仍要留起势与收势各至少 1 镜。
- 一场打斗里必须有一次**局面变化**（谁压谁被反压、谁退谁进、谁被击飞），没有变化的连续互砍不合格。

## 一、剧本层写法（三份文档里的第一份）

### 1.1 打斗场的固定行

```
## EPxxx-SCxxx 外/内 · 地点 · 时间

**场景站位**（锚点：@Sxx 场景名 · 锚点物）：两人相对的位置、朝向、承重脚、谁在高处谁在低处；机位在轴线哪一侧，明确「不越 180 度轴」。
**人物固定特征**：每人一段，写外貌＋服装＋持械手＋动作偏好（突进型／压上型）。
**场景固定特征** / **道具固定特征**：打斗要用到的台面材质、可崩裂物、可坠物；每件兵器写形状、颜色、光效、斩击痕迹。
**说话顺序**：全片无对白（或 ① 谁 → ② 谁）
**打斗回合**（本场 N 回合）
- 回合 1：谁先动｜接触点：…｜结果：…
- 回合 2：谁先动｜接触点：…｜结果：…
[LIGHT] 光源｜方向｜强度／色温｜落点｜变化
[VFX] 名称｜形态｜光源｜起｜中｜收     ← 有特效才写，照 R59
[SFX] 一回合一行（或一特效一行）三层声

（正文：一回合一段，四句式）
**表演总则**：谁全程进攻、谁居高压上、重心在前后腿怎么切换、视线追什么、两人都不看镜头。
```

### 1.2 `打斗回合` 一行三段，每段写什么

| 段 | 必写内容 | 不合格写法 |
|---|---|---|
| 谁先动 | 谁发力、往哪个方向、用哪只手／哪只脚、几拍进入接触距离 | 「两人打了起来」 |
| 接触点 | 兵器／身体在哪一高度、什么角度相接（四刀胸前咬合、刀刃磕在刀身、掌根压在护腕） | 「一顿猛攻」 |
| 结果 | 谁被推成什么姿态（后仰、下沉半步、退两步、被击飞、脚下石板裂）、留下什么（火星、碎甲、尘雾、裂纹） | 「不分胜负」 |

### 1.3 正文一回合一段，四句式

1. **起势句**：谁先动、脚下怎么蹬、重心压到哪条腿、上身朝哪；
2. **接触句**：兵器／身体怎么接上、在哪一高度哪一角度、谁架谁；
3. **受力结果句**：谁被推成什么姿态、碎什么、飞什么、光往哪爆；
4. **姿态句**：这一回合结束时两人各停在哪（含手持物位置与呼吸状态）。

四句里身体必须写到关节／肌肉／承重（膝、髋、肩、前臂、腕、咬肌、颈侧），不许只写「挥砍」「格挡」。

### 1.4 攻守交替的纪律

- 不许连续三个回合都是同一人进攻；被压的一方每回合至少有一个有效反制（架、磕、侧移、退步卸力）。
- 每回合结束必须有一方姿态变化（重心、朝向、身高、位置至少一项变了），两回合之间不许原样重来。
- 强弱要有刻度：压上的一方重心前倾、肩背前压；吃紧的一方后仰、下沉、脚下蹭退。写清「几成力」「被压得下沉多少」。
- 打斗不许凭空给能力：谁能崩石板、谁能腾空旋斩，剧本要有一句前置（武器／功法／体型），否则分镜不许加。

### 1.5 全片无对白的写法（成品就是这样）

- 剧本头写 `说话顺序：全片无对白`；分镜「台词」栏一律写 `无`；分段 `* 说话人：无`。
- 声音全部进 `[SFX]` 与分段 `overall_soundscape`：底声（高空风／室内低频）、动作声（脚步、衣甲、踏石）、击中声（金属锵鸣、闷响、甲片崩裂）、余响（碎石落地、回声）。**默认零配乐（R25）**。
- 打斗中真要说话，只能说在**回合间隙**（被击退、错身、落地、拉距离时），一句一停；刀锋相抵、贴身缠斗时开口一律不合格（口型对不上动作）。

### 1.6 `[SFX]` 声音三层（打斗版）

| 层 | 写什么 |
|---|---|
| 低频底 | 持续高空风／室内闷响／甲胄受压咯吱／踏地沉闷震响 |
| 瞬时声 | 金属锵鸣、刀刃磕碰、闷响重击、白光爆开的低频轰鸣、碎甲叮当 |
| 空间／余响 | 碎石落地噼啪渐弱、云海／空场的悠长回声、衣甲破风、非人低鸣（不成字句） |

一回合一行也行，一特效一行也行；行数要够，不许一句「打斗声」了事。

### 1.7 与特效叠用（R59）

- 兵器带光（刀气、剑气、刃光）、身上带核心、场上带法阵，就在本场照 R59 写 `[VFX]`，一行一个，与 `[SFX]` 一一对应。
- 特效的作用点是**打斗的接触点**：光团在四刀咬合处爆、核心在被劈中的胸口明灭、刀气沿斩击轨迹拖出。特效不悬空、不做背景贴图。
- 打斗的「结果」常由特效给出（白光炸开把两人推开、核心爆成强光把对手钉在原地），写结果句时把特效写进去。

### 1.8 表演总则（必写一行以上）

写清：谁全程进攻、谁居高压上；重心在突进／矮身／旋身／腾空之间怎么切换；视线各追什么（对手刀路、胸甲核心、脚下石板）；受击后仍盯住对方；两人均为第三视角记录，**视线落对方身上，不对视镜头（R49）**。

## 二、分镜层写法（第二份）

### 2.1 场标题先写打斗、再列特效

```
## 第 1 场 ｜ 云海悬空石台 · 黄昏激战（道具一红色刀气、道具二白刃相交光团、人物二胸甲核心）（来源：EP001-SC001）
```

括号里先是「地点 · 打斗性质」，再列本场 `[VFX]` 清单。看标题就知道这场怎么打、有哪些光。

### 2.2 一镜一回合，镜长与镜数（v1.50 按 R63 改）

- 打斗镜 **4–6 秒**（下限 4 秒是 H3 单次生成硬边界，R63：一镜一段、段长＝镜长）。原来 1–2 秒的快切镜不再单独成镜：把两三个连续拍并成一个 4–6 秒镜，镜内用「第一拍 → 第二拍」的连续动作交代（不写 `[Shot]`、不写时间码）。
- 一个 4–6 秒镜最多装 **1–2 个回合**（第 1–3 秒打第一回合，第 4–6 秒接第二回合）；超过两个回合就拆镜。
- 一场打斗至少 **4 镜**（起势 1 镜 ＋ 交手 ≥2 镜 ＋ 收势 1 镜），靠打斗推进的场可到 6–8 镜；15 秒左右的打斗＝3–4 镜 3–4 段（旧成品 12 镜 3 段，到本版会并成 4 镜 4 段）。
- 每个回合的镜序固定：**起势镜 → 接触镜 → 受力镜**（可并成一镜，不许颠倒）。
- 镜长与段长只写在「镜长 N 秒」「时长 N 秒」，提示词里不写时间码（R13）。

### 2.3 九栏在打斗镜里各写什么

| 栏 | 打斗写法 |
|---|---|
| 拍摄手法 | 景别＋机位高度＋运动（手持剧烈晃动／甩摇／平行跟随／俯拍下压／低角度上摇）＋镜长＋一句理由（为什么要这个机位） |
| 动作 | 一条连续动作链：起势 → 接触 → 结果，全部落在具体身体部位与兵器上；一镜不写两个回合 |
| 动作先后 | ①–⑥ 拍，按「蹬地／送肩 → 挥出 → 咬合 → 爆开 → 后仰／退步」拆开，每拍一个动作，不合并 |
| 表情 | 先一句情绪定调（几成、冲着谁），再写发力肌肉：咬肌、眉眼压低、脖颈筋线、牙关、呼吸起伏；视线写落点（对手刀路／胸甲核心／下盘） |
| 自然规律 | 受力结果写足：石板裂纹走向、碎石弹起方向、尘浪翻卷、火星下坠、瞬时强光照亮谁与投影朝哪、人物被惯性带向哪 |
| 声音 | 底声＋本镜动作声＋击中声分层，无对白写「无人物对白」 |
| 台词 | 打斗镜写 `无`；有台词只能落在回合间隙镜 |
| 参考图 | `@C01 人物一 → @图片 1` 这种绑定照旧，写全本镜用到的每个人物、场景、道具 |
| 提示词 | 见 2.4 骨架：`承接：` → `起幅：` → 动作句（起势／接触／受力／姿态）→ `转场出：` |

### 2.4 提示词骨架（照成品抄，镜头 1-2 的写法）

```
承接：上一镜人物一蹬地前冲、人物二压落到交会高度，本镜两人在台面中程正面撞上。
起幅：中景，机位平视在石台外侧，人物一在画左、人物二在画右，两人面朝彼此，白色石栏与远端浮空楼阁在背景虚化里，暖金侧光从画右打来。
人物一蹬地送肩、上身向前压，右手持道具一自下而上撩出，刀身红色焰气拖成一条竖直红痕；人物二双臂由上向下重劈，两把道具二同时压下，冷白刃光分出两道；四刀在两人胸前高度咬合相撞，正中爆出一团刺目白光，红色与白色斗气缠在交点，尘浪沿台面横向翻卷，碎石碎屑向四周飞溅；两人上身被反震力各自向后仰开。人物一咬肌鼓起、眉眼压低，视线钉在人物二胸甲核心；人物二肩臂前压，视线落在人物一刀身上。
转场出：同向运镜（镜头随冲撞后震再前压）｜末帧：白光尚未散尽，人物一偏身贴向人物二身侧，红色刀痕横在两人之间｜接：下一镜接人物一贴身绕到人物二侧翼，起手连续横斩。
```

规矩：一句一拍；每句带身体部位＋兵器＋受力结果；接触句写清「在哪一高度、什么角度、谁压谁」；末帧必须是能截住的定格姿态（供下一镜 `承接` 与下一段 `Entry` 接住，R57／R60）。

### 2.5 打斗镜的六条硬规矩

1. **不许在一个动作中途切镜**：切点在接触后、受力完成后的静止拍上；
2. **不越轴**：同场保持同一侧机位，画左画右站位不变，出入画方向一致；
3. **视线追东西不看镜头**：追对手刀路、胸口、下盘，R49／R52 照旧；
4. **一人一动作**：两人同一瞬间各写各的（谁压谁、谁在格挡），不许「两人激烈交锋」一句带过（R43）；
5. **受力必有结果**：每一击至少落一个可见结果（后仰／下沉／退步／裂石／碎甲／弹开／火星），没有结果的击打等于没打；
6. **打斗镜不塞内心戏**：表情与视线只写当场发力与判断，回忆、独白、慢镜头抒情另开镜。

### 2.6 打斗镜的转场（R57／R60）

| 转法 | 用在哪 | 写法 |
|---|---|---|
| 动作匹配 | 同场连续交手首选 | 上一镜收在刀痕／白光／旋身方向，下一镜从同一方向接进去 |
| 同向运镜 | 甩摇、横移、跟随 | 「同向运镜（横摇接横移）」「镜头随冲撞后震再前压」 |
| 出入画跟随 | 横移突进、被击飞 | 同侧出画、同侧入画，画左画右不变 |
| 遮挡转场 | 尘浪、衣袖、兵器横扫盖满画面 | 前景扫过 3–5 帧再揭开 |
| 光影过渡 | 有光效的打斗（接 R59） | 白光／红光／刀气吞满画面，下一镜从同色光里出来 |
| 跨场硬切 | 换场地 | `hard cut 至 <场名>，不沿用上一场轴线` |

禁黑场、闪白、叠化、淡入淡出（R57）；闪白只存在于「光团本身爆开的那一帧」，不是转场手段。

## 三、分镜视频层写法（第三份，格式逐字照 `references/分镜视频模板.md`）

### 3.1 段长与装法（v1.50 按 R63 改）

- **一段＝分镜的一镜**（R63），段长＝该打斗镜的 **4–6 秒**；一段只有一个 `[Shot 1]`，**不许把两个打斗镜并进一段、不许出现 `[Shot 2]`／`At MM:SS.mmm`**。
- 段内装 **1–2 个回合**：第一回合用主句写（起势动词 → 接触 → 结果），第二回合用分号接在后面（`then he ...`），两回合之间必须有一处姿态停住再起。
- 旧成品「5＋5＋5 三段 13 Shot」到本版会并成 3 段（每段 1 镜、镜内 2 回合左右）；达标看的是回合数与受力结果，不看 `[Shot]` 个数。
- 断段点选在**接触完成、姿态停住**的拍子上；不许断在挥砍半途。

### 3.2 六段字段在打斗段怎么落

| 段 | 打斗写法 |
|---|---|
| `* 时长 / 场景与轴线 / 表演参考 / 参考图 / 标签映射 / 说话人` | 说话人写 `无`；表演参考写本段命中的发力与情绪条目（突进起势、正面相撞、贴身连斩…） |
| `subject_definitions` | 人物、场景、每件兵器各占一个 `<Subject N>（图片名：人物一）`；道具写清「握在哪只手、斩击带什么光」 |
| `summary` | 一句 `[reference generation] One shot …`（R63：一段一镜），把本镜的打斗链串出来（charge → clash → close-quarters cuts → slide along the railing） |
| `retention_analysis` | 每个 Subject 一行照模板 |
| `detailed_description` | 唯一的 `[Shot 1]` 句写 1–2 个回合：起势动词 → 接触 → 结果（第二回合用 `then` 接）；有特效的用分号串阶段（R59）；一句里必须有一个受力结果 |
| `Entry` / `Exit` | 写姿态与兵器位置（谁屈膝、谁悬空、刀垂在哪侧），并与邻段按 R60 二选一 |
| `overall_soundscape` | 一句串完：风底 → 金属锵鸣 → 甲片／碎石 → 非人低鸣 → 余响，落「no intelligible dialogue」 |
| `non_diegetic_music` | `N/A`（R25） |

| 贴地横扫弧 | ground-skimming arc |
| 旋身 | spin / twist the waist |
| 腾空 | leap / airborne |
| 空中旋斩 | airborne spin slash |
| 兵刃咬合 | blades lock |
| 交叉格挡 | cross-parry |

### 3.4 打斗句的三个硬习惯

1. **一句一回合**：主句写「谁怎么动 → 兵刃在哪咬合 → 谁被推成什么姿态」；不要一句里塞三个回合。
2. **每句必带受力结果**：`blades lock` / `shockwave` / `dust wave` / `stone cracks` / `stagger` / `bracing back` / `debris flying` 至少一个，不写结果就不算写完。
3. **速度与机位必须进句**：`handheld violently shaking on impact`、`camera panning with the spin`、`low-angle looking up with the leap`——打斗的力量感一半来自机位写法。

### 3.5 段间（R60）

同一场连续打斗优先 **A 无缝接**：末帧停在接触或姿态，下一段从同一动作的下一拍起（成品的三段全是 A）。换场地、时间跳跃、被击飞落到别处才走 **B 显式转场**，方式照 R57 六种，两段同名。

## 五、验收清单（打斗十条，交付前逐条过）

1. 该场有 `打斗回合` 行，每回合都写全「谁先动｜接触点｜结果」三段。
2. 每回合正文四句式齐全（起势／接触／受力／姿态），身体写到关节肌肉承重。
3. 攻守交替：没有连续三回合同一人进攻；每回合至少一方姿态发生变化。
4. 每场至少一次局面变化（压上被反压／退走／被击飞），不是原样互砍。
5. 分镜一场 ≥4 镜、打斗镜 4–6 秒（R63 下限 4 秒）、一镜不超过 2 个回合；起势镜 → 接触镜 → 受力镜顺序不乱。
6. 每镜「动作先后」≥3 拍，每击都落了可见结果，没有「两人激烈交锋」这类笼统句。
7. 机位不越轴、视线不看镜头、贴脸与特写有视线落点（R49／R52）。
8. 分段一段一镜（只一个 `[Shot 1]`）、镜内 1–2 回合、带受力结果英文词、速度与机位写进句；术语与全片一致。
9. `[SFX]`／`overall_soundscape` 声音分层齐全，无配乐；无对白时写 `说话人：无`／`台词：无`。
10. 打斗里带光效时，`[VFX]` 照 R59 写全六段，且特效作用在接触点上；`Entry`／`Exit` 与邻段按 R60 接得上。

## 六、与既有规则的关系

- **R59 特效模板**是本模板的上层：打斗带光效时两份一起套，`[FIGHT]` 与 `[VFX]` 并存；没有光效的纯打斗只套本模板。
- **R39** 是特效底线，本模板不替代它；**R57／R60** 管镜间与段间接缝，打斗镜一律要写 `承接：`／`转场出：` 与 `Entry:`／`Exit:`。
- **R37** 一集 220–260 秒不变；**镜长 4–15 秒、段长＝镜长（R63 一镜一段）**；打斗镜自收紧到 4–6 秒、镜内 1–2 回合。
- **R43** 多人同场情绪各写各的、**R51** 分段不许缩写成「切镜＋台词」、**R25** 默认零配乐、**R49／R52** 不看镜头、**R55** 复杂接触先锁关键帧——打斗段全部照旧执行。
- **不动的东西**：九栏数量与顺序、Ref2VA 六段、分镜不写时间码、台词只说一遍、三类资产只出提示词。打斗不许新加栏目——「打斗回合」写在剧本正文之前、「回合」只落在既有九栏与六段里。
