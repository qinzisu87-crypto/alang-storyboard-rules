# 特效场景模板（R59）

> 来源：用户提供的三份成品文档（`剧本.md` / `分镜.md` / `分段视频提示词.md`，一条 28.77 秒、5 场 15 镜的玄幻修仙特效片）。
> 用途：**小说或剧本里有特效场面时，三层照这份模板写**。这是 R39「特效五件事」的成品版：R39 规定最低要求，本模板规定写到什么程度才算能投产。

---

## 零、什么时候启用

出现下列任一情况，本场按特效模板写：

| 类别 | 具体表现 |
|---|---|
| 法阵／阵法 | 地面光环、头顶同心环、六芒星、符文圈、结界、封印 |
| 能量体 | 能量巨手、光柱、光索、剑气、刀芒、掌风、护体光、法相 |
| 元素异象 | 火焰、雷、冰、风旋、雾涡、血雾、毒瘴 |
| 器物活化 | 符文锁链、飞剑、塔、钟、镜、傀儡、法器自行运转 |
| 变身与状态 | 紫能量手转黑塑、人形转法相、瞳孔变色、皮肤浮现符纹 |
| 天象／空间 | 云海涡心、巨柱升起、天地倒置、空间裂隙、幻境切换 |

纯打斗、无任何光效与超自然元素的现代戏不套本模板，仍按普通写法。

**每场特效数量**：一场 1–4 个，超 4 个拆场。一行一个，不并写、不嵌套。

## 一、剧本层写法（三份文档里的第一份）

### 1.1 每场固定四类行

```
## EPxxx-SCxxx 外/内 · 地点 · 时间

**场景站位**（锚点：@Sxx 场景名 · 锚点物）：各人相对锚点的位置、朝向、承重脚；有特效的物件也要写位置。
**说话顺序**：① 谁 → ② 谁（多人对话才写）

[VFX] 名称｜形态：…｜光源：…｜起：…｜中：…｜收：…
[VFX] 名称｜形态：…｜光源：…｜起：…｜中：…｜收：…

[LIGHT] 光源｜方向｜强度／色温｜落点｜变化

[SFX] 该场第一个特效的声音三层
[SFX] 该场第二个特效的声音三层

（正文：人物动作句与特效阶段句交替写，一段一阶段）
```

### 1.2 `[VFX]` 一行五段，每段写什么

| 段 | 必写内容 | 不合格写法 |
|---|---|---|
| 名称 | 本体叫法＋归属（`道具一 符文锁链`、`头顶同心法阵`） | 「神秘力量」「强大特效」 |
| 形态 | ① 本体材质与颜色 ② 内部结构（符文／星线／电弧／裂纹） ③ 边缘处理（泛光／毛边／速度模糊） ④ 体积与透明度（半透明紫、漆黑哑光、白色半透） | 只写「很酷的红光」 |
| 光源 | 谁照亮谁（环心照亮涡心、电弧照亮指缝、法阵自上而下打光）、投影方向、色温与冷暖 | 写「发光」不写照亮对象 |
| 起 | 从哪出现、谁触发、几拍到位、起始形态 | 「突然出现」 |
| 中 | 持续多久、怎么变、带什么风热受力、关键一次形变（如紫手→黑手） | 只写「持续发光」 |
| 收 | 怎么衰减或定型、停在哪个可截帧的状态、留下什么 | 「渐渐消失」（无法截帧） |

### 1.3 变化类特效的三段式

本体发生质变（能量→实体、光→烟、透明→实心）必须写清三件事：
1. **第几拍开始变**（在「中」里写「五指收拢后掌色由紫转沉」）；
2. **变成什么**（材质、颜色、表面处理：漆黑哑光雕塑质感）；
3. **变完停在哪**（收：黑哑巨手握链缠腕、白符沿链排开）。

### 1.4 特效与人物互锁

- 写清关系动词：握、缠、托、穿、裹、压、扣、刺、贯、绕。特效不悬空，一定作用在人或物上。
- 人物动作句与特效阶段句**交替出现**，一行一件事，不把两件事挤进一句。
- 人物受特效光照时写清「哪一侧受光、暗部压到哪」；特效不遮脸、不遮嘴、不压住台词口型。

### 1.5 天象类（云海、巨柱、法阵环、天地异象）

- **先给全景坐标**：占画面上幅／下幅、中央或左侧、水平或垂直、与地平线的夹角。
- **再给局部特写**：同一元素换到近处才有材质细节。
- 一镜不混两个尺度（大全景里不硬写纹路，特写里不写天地关系）。

### 1.6 `[LIGHT]` 一行

写五件事：光源（日光／法阵红光／电弧／柱光）、方向、强度与色温、落在谁身上、有无变化（末尾收暗就写「末尾光线整体压暗」）。**原文没写光就不加（R40）**；特效自带光源时必须写，因为它是画面主光。

### 1.7 `[SFX]` 一特效一行，声音三层

| 层 | 例子 |
|---|---|
| 低频底 | 法阵旋动的低频轰鸣、能量凝聚的低频嗡鸣 |
| 瞬时声 | 电弧噼啪、符文逐一亮起的串联脆响、链环收紧的金属闷响 |
| 空间／余响 | 长风穿过云面、余鸣在云层里铺开、衣料与发丝抖动 |

**默认零配乐（R25）**：`[SFX]` 全写画内声，不写 BGM、不写「配乐渐强」。

### 1.8 正文顺序

按「特效先起 → 人物反应 → 特效推进 → 人物再动」交替写。例：

> 人物一垂在身侧的右手手指逐根张开，指节伸直，掌心向上翻起；掌心暗红晶体浮起，白色几何光线缠绕晶体后向外展开，铺成多层同心六芒星符文法阵。

## 二、分镜层写法（第二份）

### 2.1 场标题把本场特效列进括号

```
## 第 1 场 ｜ 天象锁链与法阵云海（黑涡红环、符文锁链、能量巨手、头顶同心法阵垂落光柱）（来源：EP001-SC001）
```

括号里就是本场 `[VFX]` 的名字，看标题就知道这场有几套特效、按什么顺序出现。

### 2.2 特效落进九栏四处（R39 的四点，具体到句）

| 栏 | 写什么 |
|---|---|
| 动作 | 以 `特效：` 起头，写本体当前形态与作用对象 |
| 动作先后 | ① 起（几拍到位） ② 中（形变／峰值） ③ 收（定型或衰减） |
| 自然规律 | 特效的物理：照亮谁、投影朝哪、风热如何推动云与衣料、符文亮起的顺序 |
| 提示词 | 按 起 → 中 → 收 三个可见阶段逐行写，每阶段一句，句句可截帧 |

### 2.3 提示词骨架（照成品抄）

```
承接：同场接上一镜链环走向，锁链从画左伸入画右云雾，本镜巨手在画左握链。
起幅：巨手特写，机位略低于手腕向上仰看，半透明紫色能量大手扣在锁链中段，背景是翻涌灰云。
紫色能量巨手五指收拢扣住粗重链环，指节外张，掌心透出半透明紫光。
紫色细小电弧从指缝与腕部窜出跳动，链环内侧被紫光照亮。
手掌色泽由紫转沉，凝为漆黑哑光雕塑质感，粗锁链一圈圈缠裹住手腕与前臂。
白色符文沿缠腕链环逐段亮起，顺着链身向画右蔓延，手背被链边红光照出轮廓。
转场出：遮挡转场（链环与手臂占满画面前景）｜末帧：黑哑巨手握链缠腕，白符沿链排开｜接：下一镜仰拍大全景，从手臂与锁链方向抬起，接入头顶法阵。
```

规矩：一句一件事；每句带材质／颜色／光向；阶段之间有「随后／继而／逐渐」的时间衔接；末帧必须是稳定可截的状态。

### 2.4 用特效本身做转场桥（接 R57）

成品里特效段最爱用的三种转法，优先照用：

| 转法 | 做法 | 成品例 |
|---|---|---|
| 光影过渡 | 上一个光效（红光环、电光）占满画面，下一镜从同色光里出来 | 镜头 1-1 → 1-2：红光环眼接锁链特写 |
| 动作匹配 | 链环／刃／手的运动方向与下一镜相接 | 镜头 1-2 → 1-3：链环相接，巨手握链 |
| 遮挡转场 | 手臂、锁链、雾团、衣袍扫过镜头盖满再揭开 | 镜头 1-3 → 1-4：手臂与锁链占满画面 |

禁忌照旧：不黑场、不闪白、不叠化（原片反推除外，R58）、不遮脸遮嘴、不打断台词。

### 2.5 特效镜的镜长与机位

- 镜长 1–3 秒为主；纯天象大全景可到 3 秒，形变分解镜 1 秒内。
- 机位写清「略仰／略俯／贴近链身／自云海低处向上」，特效体积越大，机位越低或越远。
- 一镜只表现一个阶段重点，不在一镜里塞完起中收三件事（除非镜长 ≥3 秒且写明节拍）。

## 三、分段层写法（第三份，逐字照 `references/分段模板.md`）

### 3.1 六段里特效怎么落

| 段 | 特效写法 |
|---|---|
| `subject_definitions` | 场景与道具各占 `<Subject N>（图片名：场景一）`／`（图片名：道具一）`，供给句照模板；特效本体若属道具（锁链、法阵器物）就算道具 Subject；纯光效不入 Subject |
| `summary` | 一句里把本段特效点出来（`a black vortex forms a red rune ring, a giant chain and an energy hand reach down`） |
| `retention_analysis` | 每个 Subject 一行照模板；纯光效不占行 |
| `detailed_description` | 每个 `[Shot N]` 句内用**分号串阶段**：`translucent purple palm glowing through, purple arcs crackling between fingers and wrist; the palm then turns to a matte black sculpted surface, the chain coiling around wrist and forearm, white runes lighting link by link` |
| `Entry` / `Exit` | 用特效的定格状态做接缝（`the segment ends on the concentric red array overhead with the light pillar dropping to the cloud surface`） |
| `overall_soundscape` | 一句里串多声源：风、低频轰鸣、金属拖拽、电弧、翼振，最后落到「只有画内声」 |

### 3.2 英文术语固定表（同一特效全片用同一个词，不换同义词）

| 中文 | 英文（分段正文统一用这个） |
|---|---|
| 法阵／阵法 | rune formation / rune array |
| 同心法阵环 | concentric rune rings |
| 符文 | rune(s) |
| 符文锁链 | rune-etched chain |
| 光柱 | light pillar |
| 光索 | light cord |
| 电弧 | arc(s) / crackling arcs |
| 能量巨手 | giant energy hand |
| 紫色能量／半透明 | translucent purple |
| 漆黑哑光 | matte black |
| 涡心／涡旋 | vortex heart / vortex |
| 结界 | ward |
| 法相／巨像 | giant avatar |
| 符箓 | talisman |
| 剑芒／刀芒 | blade light |
| 火焰／火舌 | flame / tongue of fire |
| 雷电 | lightning bolt |
| 冰棱 | ice shard |
| 血雾 | blood mist |
| 幻境 | illusion space |

### 3.3 特效句的三个硬习惯

1. **一句一阶段，分号分阶段**，不用逗号堆三件事。
2. **颜色与材质必须出现在句子里**（`matte black`、`glowing runes`、`pale white halo`），不写 `cool effect`、`strong light`。
3. **写光写亮写影**：`lights the vortex heart`、`casting his shadow on the right wall`——光是特效的证明，不写光就等于没写特效。

## 五、验收清单（特效十条，交付前逐条过）

1. 本场 `[VFX]` 每个都写全了 名称／形态／光源／起／中／收 六段，没有「炫酷」「特效拉满」。
2. 形态里能读到材质、颜色、内部结构、边缘、体积五件事。
3. 光源写清了照亮谁、投影朝哪、冷暖；对面部的影响写了。
4. 「收」停在可截帧状态，与下一镜「承接／Entry」能接上。
5. 形变类特效写了「几拍开始变 → 变成什么 → 变完停在哪」。
6. 特效与人物有明确作用关系（握／缠／托／穿／裹），不是背景贴图。
7. 分镜里同一特效落进了「动作／动作先后／自然规律／提示词」四处。
8. 分段每个 Shot 句用分号串阶段、带颜色与材质英文词，术语与全片一致。
9. `[SFX]` 一特效一行、三层齐全，没有 BGM／配乐（R25）。
10. 特效没有遮脸遮嘴、没有压住台词口型、没有越轴、没有与 R57 六种转场冲突。

## 六、与既有规则的关系

- **R39** 是底线（五件事齐全），本模板是成品标准（写到能投产能截帧）；冲突时按本模板写得更细。
- **R40**：原文没写光就不加光；但特效自带光源必须写进 `[LIGHT]`、分镜「自然规律」、分段 `detailed_description` 与 `overall_soundscape`。
- **R57**：特效段落优先用光影过渡／动作匹配／遮挡转场做桥，禁黑场闪白叠化（反推原片除外，R58）。
- **R58**：视频反推遇到特效片，就按本模板的三层写法复刻，图槽仍写 `人物一／场景一／道具一` 占位。
- **不动的东西**：九栏数量与顺序、Ref2VA 六段、分镜不写时间码、台词只说一遍、默认零配乐、人物不看镜头、三类资产只出提示词——全部照旧。特效不许新加栏目，只能落进既有九栏与六段。
