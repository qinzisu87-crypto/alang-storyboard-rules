# 正文镜头语法（Ref2VA 口径）

`detailed_description` 用的镜头语法。本剧默认一镜一段，所以实际只用到第 1 节的单镜写法与第 2、3、5、6 节；第 1 节末尾的多镜切点是例外条款。

## 1. `[Shot N]` 与切点

- `[Shot 1]` 不带时间码；一镜一段时全文只有这一个镜头块，**不出现 `[Shot 2]` 与 `At MM:SS.mmm`**。
- 例外：用户当次明确要求把两镜合成一次生成（例如两个 2 秒短镜并成一次 5 秒输出），才允许 `[Shot 2] At 00:03.500, the shot cuts to ...`；时间格式 `MM:SS.mmm`、严格递增、落在段长内。除此之外一律回分镜加镜、另起一段。
- 切镜动词：`the camera cuts to`／`the shot cuts to`／`the shot transitions to`／`the shot changes to`／`the shot switches to`；叠化、淡入淡出、划像只在用户明确要求时用。
- 切镜必须带来新信息（主体、空间、状态、视点、时间）；只是景别或轻微角度变化，用运镜，不要切。

## 2. 运镜三要素

**类型 + 幅度（`with small/large amplitude`）+ 速度（`at slow/fast speed`）**，中幅常规速可省。写成句中自然动作，不许句尾堆标签。

| 类型 | 含义 |
|---|---|
| `Zoom In / Zoom Out` | 变焦，机身不动 |
| `Push In / Pull Out` | 机身推进／后退 |
| `Pan Left / Pan Right` | 原地水平摇 |
| `Truck Left / Truck Right` | 水平平移 |
| `Tilt Up / Tilt Down` | 原地垂直摇 |
| `Pedestal Up / Pedestal Down` | 整机升降 |
| `Arc Shot` | 绕主体弧线运动 |
| `Tracking Shot` | 跟随运动主体 |
| `Static Shot` | 机位与镜头不动 |
| `Shake Slightly / Shake Strongly` | 轻微／强烈晃动 |
| `POV` | 主体视角（本剧剧情镜不用，R49） |
| `Roll Clockwise / Roll Counterclockwise` | 绕镜头轴滚转 |

```text
The camera holds a static shot at a slight low angle while the incense smoke drifts through frame left.
The camera pushes in with small amplitude at slow speed toward the scabbard under his palm.
```

镜头层还要读得出：景别、焦段（只写效果，不写器材名，R55）、机位高度、俯仰、轴线在一侧。

## 3. 说话人 ID 与 `<d>`

- 发声主体用稳定 ID `(S1)`、`(S2)`，按发声先后分配；多人同时说话用 `(S1,S2)`；不发声的不给 ID。
- **身份、ID、动作、语气写在 `<d>` 外；`<d>` 内只放语言标签和原话。**

```text
<Subject 1> (S1) says in a thin mid-range voice, at six parts volume: <d>[Chinese] 墨微雨法力高深，为人阴毒，还是谨慎为上。</d>
<Subject 2> (S2) answers in a flat low voice, <d>[Chinese] 走吧。</d>
```

- 原话逐字保留，标点照抄，不翻译、不改写；`<d>` 内不加动作、不加表情。
- 画外音固定短语 `says in an off-screen voiceover`，紧跟一句嘴部状态：

```text
<Subject 1> (S1) says in an off-screen voiceover: <d>[Chinese] 我从下一站下车。</d> while his lips remain completely closed.
```

- 独白镜写 `keeps his lips closed while the inner monologue runs`，不张嘴。

## 4. 跨切与截断（仅多镜例外时用）

- 同一句对白跨切：两端连接处都插 `<scenetrans>`，并写明音频跨切连续（`continues seamlessly across the cut`）。
- 被片尾截断：用 `<cutoff>`。
- 句尾留一条缝、气从缝里出去这类细节，用 `his lips stay slightly parted` 这类可见描述补。

## 5. 画面可见文字

招牌、匾额、符牌、字幕等真实出现在画面上的文字，用英文双引号包住原文，不翻译：

```text
A carved plaque reading "死生之巅" hangs above the stone steps.
```

## 6. 两段音频的分工

| 声音 | 写在哪 |
|---|---|
| 对白、歌唱、画内音乐 | `detailed_description` 的 `<d>` 或叙述里 |
| 与某一镜同步的音效 | `detailed_description` |
| 全片环境声、物理声、非语言人声 | `overall_soundscape`（1–4 句） |
| 只有观众听得到的配乐 | `non_diegetic_music`（1–3 句，无则 `N/A`） |

`overall_soundscape` 与 `non_diegetic_music` **不重复**正文里的对白与画内音乐。
