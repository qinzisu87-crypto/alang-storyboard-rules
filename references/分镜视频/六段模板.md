# 分镜视频六段模板（一镜一段）

直接照填。填之前先把镜头表第 N 行与文本分镜第 N 节摊在旁边，两边都要用上。

```
## 第 N 段 ｜ 镜 <集>-<序> / <N>s ｜ <镜名，与镜头表同名>

* 参考图：@图片 N @图片 N
* 说话人：(S1) 名 → (S2) 名

  subject_definitions:
  <Subject 1> is 中文名 (C0x), the <身份／年龄感／体型> in <Picture 1>, with <发式>, <服装款式与磨损>, <随身物>.
  <Subject 2> is 场景中文名, the <地点> in <Picture 2>, with <布局与锚点物>, <材质>, <光位>.
  summary:
  [reference generation] One shot <一句英文：这一镜生成什么、谁在哪、做什么>
  retention_analysis:
  <Subject 1> (appears in [Shot 1]): fully_preserved - <保留的特征>.
  <Subject 2> (appears in [Shot 1]): weak_reference - <只保留的质感，布局按分镜>.
  detailed_description:
  <参考画风质感词 1–2 句，写在 [Shot 1] 之前>
  [Shot 1] <景别>, <机位与运动>: <首句承接上一镜末帧状态>. <动作链，含关节／承重／位移>. <表情句，情绪几成＋眉／眼／瞳孔／鼻／嘴／喉／肩颈／手>. <<Subject 1> (S1) says …, <d>[Chinese] 原文</d>. His lips close …> <末句停在静止点，写清交给下一镜的那一拍>.
  overall_soundscape:
  <环境声、物理声、非语言人声 1–4 句>
  non_diegetic_music:
  N/A
```

## 填之前先核对的清单

```
镜号与秒数（镜头表列1）：镜 __-__ / __s
段长是否＝镜长：__（4–10 整数）
参考图槽（列3）：@图片 __
说话人（列6）：(S1) __ (S2) __（无人说话写「无」）
台词句数（列6）：__ 句，原文逐字，只写一次
列2 交接：上接 __ ；下交 __
列5 逐秒条数：__ 条（＝秒数）
文本分镜节数：第 __ 节，十一字段是否齐
表情几成与视线落点：__
光位与投影（只照原文）：__
```

## 三条填空纪律

- 词数落在 350–500 英文词；台词密集时以发声时间排满。
- `[Shot 1]` 只有一个，不写时间码；要切镜就回分镜加镜。
- 台词只进 `<d>[Chinese] 原文</d>`，一句一处；`summary`、`retention_analysis`、`overall_soundscape` 都不抄台词。
