# 分镜视频取料对照（双源合一）

分镜视频提示词不是另写一份，是把**镜头表**与**文本分镜**两份合起来，译成 H3 听得懂的六段。两份缺一不可：镜头表给结构（秒数、镜头、逐秒动作、台词原文、声音总谱），文本分镜给细节（每格姿态表情、视线、道具位置、光与声、构图草图）。

## 0. 什么时候写：用户点头才写（R71.1）

1. 分镜两件（`分镜/镜头表.md` ＋ `分镜/文本分镜.md`）交付出去，等用户确认。
2. 用户确认后，**先问一句**：「分镜可以了，要不要继续出分镜视频提示词？」
3. 用户说「继续／要／出提示词」→ 才写 `分镜视频.md`，与 `项目交接.md` 同批交付。
4. 用户说「先到这儿／不要／先看分镜」→ 本轮只交两份分镜，**不写 `分镜视频.md`**，也不在报告里写「待补」；脚本不判缺。
5. 不许在分镜那一轮顺手把提示词写了，也不许把提示词写到一半再问。

## 1. 第 N 段＝第 N 镜（R63）

- 段数＝镜数，一段只装一镜，段内只有一个 `[Shot 1]`。
- 段标题写 `## 第 N 段 ｜ 镜 <集>-<序> / <N>s ｜ <镜名>`，段长逐字等于镜长（4–10 整数秒）。
- 段首元数据两行（供审阅对账，不贴给工具）：`* 参考图：@图片 N …`、`* 说话人：(S1) 名 → (S2) 名`（无人说话写 `无`）。

## 2. 逐栏取料表

| 六段里的位置 | 取自镜头表哪一列 | 取自文本分镜哪一节 | 怎么译 |
|---|---|---|---|
| 段标题与段长 | 列1 `镜 1-3 / 6s` | 该镜节标题 | 原样搬，段长＝秒数 |
| `* 参考图` | 列3 身份绑定 `@Cxx @Sxx @图片 N` | 该镜「图槽」字段 | 只留 `@图片 N`，不写 `@Cxx` |
| `subject_definitions` 人物 Subject | 列3 角色位置＋身份绑定 | 「场景与站位」「人物」行 | `<Subject N> is 中文名 (C0x), …参考特征…`；图只定义长相就折进 Subject，不单开 Picture |
| `subject_definitions` 场景 Subject | 列3 固定地标与光照基线 | 「场景与轴线」字段 | 写布局、锚点物、材质、光位；不给机位 |
| `subject_definitions` 道具 Subject | 列3 绑定里的 `@Pxx` | 该镜道具字段 | 写形状、尺寸、材质、磨损 |
| `summary` | 列1 秒数＋列5 镜头层 | 该镜「起幅」 | `[reference generation] One shot …`（有首帧图才 `[keyframe completion]`） |
| `retention_analysis` | 列3 绑定 | — | 一项一行带 `(appears in [Shot 1])`；可见四档、音频四档；不写 `(Sx)` |
| `detailed_description` 风格句 | 无（取参考画风质感） | — | 1–2 句，写在 `[Shot 1]` 之前 |
| `[Shot 1]` 冒号前的景别与机位 | 列5 镜头层（景别／焦段／机位高度／俯仰／轴线／运动） | 「机位」字段 | `<景别>, <机位>: …`，运镜写三要素或直接写效果 |
| 正文动作链 | 列5 逐秒指令（每秒一条，五要素） | 逐格四象限的「动作／姿态」 | 条数不减：几秒几条就几组动作分句，关节、承重、位移照原顺序 |
| 正文表情句 | 列5 逐秒的表情与视线＋列6 表演提示 | 逐格「表情」 | 情绪（几成、冲谁）→眉／眼／瞳孔／鼻／咬肌／唇／喉／肩颈／手 |
| 正文光与物理 | 列3 光照基线＋列5 光的描述 | 逐格「光与影」 | 光位、投影方向、雾、水痕、白气，只照原文 |
| 台词 | 列6 对白（原文只在这里出现一次） | 逐格只写 `mouth-open: 谁`，不抄原文 | `<d>[Chinese] 原文</d>` 逐字，一句一处，`(Sx)` 按发声顺序 |
| `overall_soundscape` | 列6 音效锚点＋嗓音提示 | 逐格「音频」 | 1–4 句环境声、物理声、非语言人声；不抄台词 |
| `non_diegetic_music` | — | — | 默认 `N/A`（R25） |
| 首句承接 | 列2 交接「从上一镜怎么长出来」 | 该镜「承接」字段 | `[Shot 1]` 第一句写接住上一镜末帧（姿势／朝向／重心／手持物／光位） |
| 末句停点 | 列2 交接「怎么给下一镜开口子」 | 该镜「转场出」字段 | 末句停在可截帧的静止点，写清交给下一镜的那一拍 |
| 构图校准 | — | ASCII 草图 | 只看人不看字：谁在画左画右、头顶留多少空，不把草图字符译进正文 |

## 3. 译写四条红线（R66 照旧）

1. **只译不写**：动作、台词、道具、表情、光、特效阶段全部来自两份分镜；分镜没写的，不在这一层现编。
2. **不换动作**：分镜写「掌根压刀柄」，不许译成「拔刀」；分镜 5 拍，正文也 5 组动作分句。
3. **不改机位**：景别、焦段、机位高度、俯仰、轴线、运动、镜长照分镜；分镜没写运镜就是 `Static Shot`。
4. **不译说明**：分镜里的「理由：」「为了让……」是给人看的，只把它的可见结果写出来（`the slight low angle lets the banner loom behind him`），英文不出现 `because`／`so that`／`in order to`。

## 4. 交付前对账

逐段并排读三样：镜头表第 N 行、文本分镜第 N 节、`分镜视频.md` 第 N 段。

- 六段齐不齐、顺序对不对；
- 景别／机位有没有改，动作拍数有没有少，台词是不是逐字、只出现一次；
- 表情的几成与肌肉有没有逐项落到英文句，视线落点有没有写；
- 有没有多出分镜没有的动作、台词、道具、镜头；
- 段数＝镜数、段长＝镜长、段内只有一个 `[Shot 1]`。

对不上就重译，不改分镜、不改剧情。
